# 按影响验证

- Python/测试/导出接线：运行 `mem:suggested_commands` 中的unittest入口；目录迁移还要确认导出副本能用同一入口运行。真实客户端试用是否适用，按AGENTS.md中的客户端运行行为影响判断。
- Dockerfile/原生构建：容器内完整构建，核对实际镜像身份/入口/资源外置；不要回退宿主编译或把端口连通当作游戏就绪。
- 控制行为：授权角色与隔离目标确认实际动作、取消放键、必要的存档/重开。IPC桩只证明协议边界；GUI原语与无头能力分别判断。
- 按AGENTS.md选择简易或完整交付流程；纯文档使用简易流程，代码与构建改动核对docs/CI.md中的常规检查，并按影响判断真实客户端试用范围。CI不配置为远端强制门禁；本地成功不代替远端CI结果。
- 收尾只回收本轮资源，保留既有改动；检查git diff --check与子模块工作树。用户选定并授权推进需求后，按AGENTS.md自主提交/推送、建PR、验收与合并；入池不自动启动开发。
- 稳定约定变化时纠正相关记忆并运行serena memories check；临时任务过程/凭据/运行数据不写入记忆。
