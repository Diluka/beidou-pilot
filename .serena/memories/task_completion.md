- Python/测试/导出接线：运行 `mem:suggested_commands` 中的unittest入口；目录迁移还要确认导出副本能用同一入口运行。真实客户端试用按AGENTS.md中的客户端运行行为影响判断适用范围。
- Dockerfile/原生构建：容器内完整构建，核对实际镜像身份/入口/资源外置；游戏就绪以启动日志和只读 API 为准。
- 开发调试和复现在独立开发服准备样本，按 AGENTS.md 核对分区、版本、条件和真实客户端结果；匹配的开发样本可用作正式证据。按 GUI 实际影响覆盖，服务端准备、IPC 合同、实际动作、取消放键和关闭分别报告。常驻数据不作样本准备。
- 按 AGENTS.md 选择简易或完整交付流程；纯文档使用简易流程，代码与构建改动核对 docs/CI.md 中的常规检查，并按影响判断真实客户端试用范围。CI 通过以对应提交的远端结果为准。
- 收尾只回收本轮资源，保留既有改动；检查 `git diff --check` 与子模块工作树。执行维护者明确指定的任务时，只交付该任务范围。
- 当前应用层按 `docs/COMPANION_BOT.md` 的阶段和验收推进；旧 Issue/PR 不是路线图。
- 稳定约定变化时纠正相关记忆并运行 `serena memories check`；临时任务过程、凭据和运行数据不写入记忆。
