# 北斗游戏攻略

## 已覆盖的攻略

- [彩虹岛新手任务](references/newbie.md)：两套任务的入口、顺序、奖励、返回原版流程、快捷跳过条件和正常乘船路线。回答新手任务问题或继续研究这条路线时，先读此文及其核验范围。

- [冒险家二转加点](references/adventurer-second-job.md)：12条分支的终态方案、121 SP预算、AP主副属性、武器取舍及四转对二转的显式前置。

- [冒险家三转加点](references/adventurer-third-job.md)：12条分支的终态方案、151 SP预算、武器取舍及11条四转对三转的显式前置；四转阶段规划尚未覆盖。

## 查阅与维护

根据角色当前地图、等级、职业和任务记录选取适用步骤。保留资料中的版本与验证状态，区分资源规则、源码推断和实际试玩；未实测的分支不要说成已经走通。

新增证据时优先更新对应攻略；入口只维护覆盖范围和链接，详细规则集中在参考资料。每篇攻略保留可查阅的来源、适用范围、关键条件与结果核对方法。

需要实际进入游戏核验时，按 [客户端操作技能](../beidou-pilot-client/SKILL.md) 找回授权角色、目标与已有实例，再观察并接续；攻略中的路线与收益不代替当前角色的实际状态。
