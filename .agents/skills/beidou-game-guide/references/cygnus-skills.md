# 骑士团各转职阶段终态加点

想知道每转结束时技能该加到多少，可以直接找自己的职业表。本文覆盖北斗 V17 的魂骑士、炎术士、风灵使者、夜行者、奇袭者，只列阶段终态，不展开逐级顺序。配点按技能资源与源码整理，尚未逐职业试玩；圣地任务与一转选职见[新手攻略](cygnus-newbie.md)。

## 阶段与点数预算

骑士团五系均10级一转、30级二转、70级三转，最高120级。下面的一转表对应30级转职前，二转表对应70级转职前，三转表对应120级。骑士团到三转结束，没有120级四转的加点阶段。

| 阶段 | 结算时点 | 本阶段SP预算 |
| --- | --- | ---: |
| 贵族 | 7级后可用满 | 独立6点 |
| 一转 | 30级升级后、二转前 | 1＋20×3＝61 |
| 二转 | 70级升级后、三转前 | 1＋40×3＝121 |
| 三转 | 120级升级后 | 1＋50×3＝151 |

以上点数按及时转职、每级3 SP、每次转职奖励1点计算。**这是每阶段新得到的点数，表里的数字则是技能最终等级。**三阶段的表各自分配本阶段获得的SP，之前已经加过的技能另算。

如果你的点数和表格对不上，先把已花的点数与剩余SP加在一起，看看是否延迟过转职、拿过额外赠点，或把后阶段的点补到了旧技能上。服务器若开启职业SP补偿，炎术士的可用点数也可能不同，不能只看剩余SP照表重加。

贵族建议：**蜗牛投掷术3、疾风步3、团队治疗0**，合计6点。精灵的祝福、骑兽技能等要靠账号或任务条件获得，不占这6点。

## 能力值AP

| 职业 | 主属性 | 副属性 | 武器路线 |
| --- | --- | --- | --- |
| 魂骑士 | STR | DEX | 剑；精准、快速等支持剑系，不照搬冒险家斧修 |
| 炎术士 | INT | LUK | 法杖 |
| 风灵使者 | DEX | STR | 弓；不能将本表换成弩技能 |
| 夜行者 | LUK | DEX | 拳套、飞镖 |
| 奇袭者 | STR | DEX | 拳甲；不是火枪路线 |

副属性补到目标装备实际需求，计入装备加成，其余加主属性；不固定4∶1分配。物理职业另查命中。AP与SP分开核算，骑士团特有的升级AP奖励不等于额外SP。

生命加强、魔力强化、强体术会影响升级时的HP／MP成长，练级时要尽早加。这些表只写最终等级，拖到阶段末才补满，并不会补回之前少长的HP／MP。

## 魂骑士

职业ID：一转1100 → 二转1110 → 三转1111。主修剑，保留群攻、移动、斗气及圣属性支持。

### 一转终态（61 SP）

| 技能 | 终态等级 |
| --- | ---: |
| 生命加强 | 10 |
| 圣甲术 | 0 |
| 强力攻击 | 20 |
| 群体攻击 | 20 |
| 魂精灵 | 11 |
| **合计** | **61** |

优先完整保留基础单攻、群攻与成长，圣甲术作为舍弃项；偏好防御可改圣甲术10、魂精灵1，仍61点。

### 二转终态（121 SP）

| 技能 | 终态等级 |
| --- | ---: |
| 精准剑 | 20 |
| 快速剑 | 20 |
| 终极剑 | 21 |
| 愤怒之火 | 20 |
| 灵魂之刃 | 30 |
| 灵魂迅移 | 10 |
| **合计** | **121** |

保留远距群攻与快速移动，终极剑省9点。快速剑需要精准剑5，终极剑需要精准剑3，这套加法都能满足。

### 三转终态（151 SP，按任务所列解锁等级保守规划）

| 技能 | 终态等级 |
| --- | ---: |
| 魔力恢复 | 11 |
| 斗气集中 | 20 |
| 恐慌 | 20 |
| 昏迷 | 20 |
| 轻舞飞扬 | 20 |
| 进阶斗气 | 10 |
| 灵魂突刺 | 30 |
| 灵魂属性 | 20 |
| **合计** | **151** |

**完成100／110级训练后，先看轻舞飞扬和进阶斗气能加到几级。**任务奖励写的上限分别是20、10，技能资料却是30、20；目前还没实际确认客户端会开放到哪一档，上表先按20／10来分配。

如果技能栏确认可以加到轻舞飞扬30、进阶斗气20，可选进攻方案：**魔力恢复0、斗气集中20、恐慌11、昏迷20、轻舞飞扬30、进阶斗气20、灵魂突刺30、灵魂属性20**，仍151点。选这套之前，务必先看清自己的技能上限。

进阶斗气要求斗气集中20；恐慌、昏迷需要斗气集中1。两套终态都满足。轻舞飞扬与进阶斗气的解锁任务见[技能训练](#100110级的技能训练)。

## 100／110级的技能训练

下表的技能要通过训练任务解锁，刚三转时还看不到。100级找南哈特做 **未尽的修炼（20600）**，再找本职业团长接20601～20605；110级做 **仍未结束的修炼（20610）**，再接20611～20615。进入第三／第四演武场，取得本职业证物后回团长交任务。进不去时，看看任务是否已接、背包里是否已经有证物；若提示场内有人，稍后再来。

| 职业 | 100级任务 → 技能／任务所列能手等级 | 110级任务 → 技能／任务所列能手等级 |
| --- | --- | --- |
| 魂骑士 | 20601 → 轻舞飞扬11111004／20 | 20611 → 进阶斗气11110005／10 |
| 炎术士 | 20602 → 火魔兽12111004／20 | 20612 → 天降落星12111003／20 |
| 风灵使者 | 20603 → 暴风箭雨13111002／20 | 20613 → 神箭手13110003／20 |
| 夜行者 | 20604 → 三连环光击破14111005／20 | 20614 → 武器用毒液14110004／20 |
| 奇袭者 | 20605 → 光速拳15111004／20 | 20615 → 极速领域15111005／20 |

完成训练只是解锁技能，还要花自己的SP去加，任务不会直接把技能送到满级。魂骑士两项技能的上限有差异，按上面的职业说明选择方案；其余八项的任务上限与技能资料一致。

资料中没有找到这些职业技能对应的228技能书或229能手册，100／110级的新技能应先去做训练任务。

## 已经加过点的角色怎么参考

表中的数字是最终等级。例如技能已经10级、表中写20级，就再补10点。先看自己缺哪些技能，再算剩余SP是否够用；如果以前用二转或三转的点补过旧技能，也要把这部分算进去。

有几项前置特别容易漏：风灵使者的精准弓要20才能学神箭手；奇袭者的急速拳要20才能学极速领域，能量获得至少1才能学能量耗转；夜行者想加驱逐，则要先有隐身术10。

100／110级训练做完后再给新技能分点，魂骑士还要留意轻舞飞扬和进阶斗气的上限。若自己的技能上限或可用SP与表格不同，先保留剩余点数，查清差额后再补。

## 资料来源与实测范围

资料版本为北斗 V17，源码参考 [BeiDou-Server `00422c2`][source]。本地 `Skill.nx、String.nx` 中124项贵族与骑士团技能的名称、上限、前置，与公开资料一致，其中一至三转职业技能共98项。15张主表与文中的换点方案都已检查点数和前置；100／110级训练的10项奖励也已对照任务资料，魂骑士两项上限差异见正文。

实际加点、训练解锁与战斗效率尚未逐职业试玩。SP按公开默认设置计算，不同服务器设置可能影响点数；贵族页的活动、隐藏及自动技能不计入自主分配的6点。

公开依据：

- [技能资源目录][skills]：文件为 `1100、1110、1111、1200、1210、1211、1300、1310、1311、1400、1410、1411、1500、1510、1511.img.xml`；贵族是 `1000.img.xml`。`level` 表示资源各级效果，`req` 表示显式技能前置，隐藏技能看 `invisible`。
- [中文技能名称与说明][strings]：含使用状态、武器与消耗提示；炎术士精神力的残留前置文字需与实际 `req` 分开。
- [转职奖励、升级SP与等级上限][character]：`changeJob、levelUpGainSp、getMaxLevel`；[公开默认配置][config]每级3 SP、关闭强制SP范围；[职业树与SP规则][constants]、[SP分配处理器][assign]核对职业归属、贵族6点及三转／四转上限处理的区别。
- [快速转职脚本][advance]：10／30／70级、骑士团三转后结束。不以该脚本后部未到达的四转初始化分支宣称支持四转。
- [任务条件][check]、[技能授予][act]及[中文覆盖目录][questzh]：20600～20615；[任务技能动作实现][skillaction]解释默认0级与能手等级合并。
- [第三演武场入口][third]、[第四演武场入口][fourth]：任务、证物与场地占用检查；尚未实测挑战、掉落与交付。
- [228技能书][books228]、[229能手册][books229]：已检索映射，未发现本篇职业技能。

整理日期：2026-11-11。这些方案以保留常用攻击、移动和辅助能力为主；文中也给出了偏重防御、回复或控制的换点办法，可以按常去的地图和组队习惯选择。
