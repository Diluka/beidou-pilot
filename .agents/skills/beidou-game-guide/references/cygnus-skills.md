# 骑士团各转职阶段终态加点

适用范围：北斗 V17 的魂骑士、炎术士、风灵使者、夜行者、奇袭者。2026-11-11 按本地技能资源与固定公开源码核对，**所有配点均为研究建议，尚未逐职业实际加点或比较战斗效率**。只给各阶段终态，不列逐级投入顺序。圣地任务与一转选职见[新手攻略](cygnus-newbie.md)。

## 阶段与点数预算

骑士团五系均10级一转、30级二转、70级三转，等级上限120；本篇的三转终态在120级结算。**没有正常的120级四转配点表**：快速转职脚本的骑士团分支在三转后明确结束；其他代码中出现“骑士团四转”字样或职业占位，不代表实际开放第四阶段。

| 阶段 | 结算时点 | 本阶段SP预算 |
| --- | --- | ---: |
| 贵族 | 7级后可用满 | 独立6点 |
| 一转 | 30级升级后、二转前 | 1＋20×3＝61 |
| 二转 | 70级升级后、三转前 | 1＋40×3＝121 |
| 三转 | 120级升级后 | 1＋50×3＝151 |

预算以及时转职、每级3 SP、各次转职奖励1点、无额外赠点为基准。**这是每一阶段新增点数，表内数字则是技能最终等级。**之前阶段的投入另计；只有表中明确要求追加旧技能时才从当前阶段扣除，本篇主方案没有跨阶段补点。

默认公开配置未开启强制职业SP范围；若另一个目标开启了该配置，源码还含法师系补偿逻辑，炎术士的可用点数可能与本基准不同。延迟转职、已有旧技能投入、额外赠点也会改变账面值。先核对实际记录，出现差额就停下复核，不能直接把“剩余SP”当作本阶段全部所得，也不能借高转点数掩盖前一阶段超支。

贵族建议：**蜗牛投掷术3、疾风步3、团队治疗0**，合计6点。精灵的祝福、骑兽技能等由账号或任务条件决定，不占这6点的自主配点预算；不把整个贵族页的所有技能都当作可自由点满项目。

## 能力值AP

| 职业 | 主属性 | 副属性 | 武器路线 |
| --- | --- | --- | --- |
| 魂骑士 | STR | DEX | 剑；精准、快速等支持剑系，不照搬冒险家斧修 |
| 炎术士 | INT | LUK | 法杖 |

副属性补到目标装备实际需求，计入装备加成，其余加主属性；不固定4∶1分配。物理职业另查命中。AP与SP分开核算，骑士团特有的升级AP奖励不等于额外SP。

生命加强、魔力强化、强体术包含升级时HP／MP成长效果。本文是终态表，**不意味着拖到阶段末才补满能追补此前成长**；养成中仍应及时处理这类成长技能。不要为了补救历史差额贸然洗点或洗血。

## 100／110级的技能训练

这些技能在资源中带 `invisible=1`，不应在刚三转时就假设已全部开放。100级找南哈特做 **未尽的修炼（20600）**，再找本职业团长接20601～20605；110级做 **仍未结束的修炼（20610）**，再接20611～20615。按任务进入第三／第四演武场、取得本职业证物，再回对应团长交付；入口会检查任务进行中、是否已有证物及演武场是否被占用。

技能奖励项未设置 `skillLevel`，服务端默认按0级登记，并合并现有等级与能手等级；**解锁不等于免费送满技能，也没有给本表另外增加SP**。魂骑士的任务值与资源上限差异已在职业段落说明，其余八项任务值均与本地技能上限一致。

没有发现228技能书／229能手册映射到本篇15个一至三转职业的技能。由此只能说不能按普通冒险家四转买书路线代替上述训练，不代表骑士团不需要任何任务或使用条件。

## 分配前与阶段结束时核对

1. 按职业ID和技能页选表，确认武器路线、已有技能等级及剩余SP。数字是终态，已有10级、目标20级时只补10点。
2. 一转、二转、三转分别新增61、121、151点；核对选择的替代方案，也检查是否曾把后阶段SP补到旧技能。
3. 跨转前置至少查：精准弓20 → 神箭手；急速拳20 → 极速领域；能量获得1 → 能量耗转；隐身术10 → 驱逐（仅在准备学习驱逐时）。同阶段前置以各表说明及资源 `req` 为准。
4. 100／110级训练完成后，确认技能已显示、允许上限正确，再追加SP。魂骑士未确认高上限时使用保守方案。
5. 技能效果受武器、药品、变形、能量和目标影响。配点核验不替代真实使用验证；若名称、上限、前置或SP账不符，停止新增投入并记录技能ID和实际读数。

- [转职奖励、升级SP与等级上限][character]：`changeJob、levelUpGainSp、getMaxLevel`；[公开默认配置][config]每级3 SP、关闭强制SP范围；[职业树与SP规则][constants]、[SP分配处理器][assign]核对职业归属、贵族6点及三转／四转上限处理的区别。
- [快速转职脚本][advance]：10／30／70级、骑士团三转后结束。不以该脚本后部未到达的四转初始化分支宣称支持四转。
- [任务条件][check]、[技能授予][act]及[中文覆盖目录][questzh]：20600～20615；[任务技能动作实现][skillaction]解释默认0级与能手等级合并。
- [第三演武场入口][third]、[第四演武场入口][fourth]：任务、证物与场地占用检查；尚未实测挑战、掉落与交付。
- [228技能书][books228]、[229能手册][books229]：已检索映射，未发现本篇职业技能。

本篇只维护骑士团阶段终态；不承诺一种配点在所有装备、地图、队伍与控制策略下最优。需要效率排名时，应另提出具体场景，并由获授权玩家比较实际收益。
