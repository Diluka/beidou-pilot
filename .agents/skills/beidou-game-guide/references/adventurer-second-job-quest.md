# 冒险家二转任务攻略

冒险家一转后达到30级，即可选择二转分支。本文覆盖战士、魔法师、弓箭手、飞侠和海盗；骑士团、战神不走这条路线。转职后参照[二转加点规划](adventurer-second-job.md)。本文依据北斗服务端脚本静态整理，尚未逐职业实测；实际提示和当前服务器设置可能不同。

## 先确认是不是二转

**30级后优先转职，不要因为接到导师的其他任务而继续练级等待。** NPC 相同不代表任务相同：以本篇对应职业的二转对话、任务编号和实际交付物为准；其他打怪、送信或主题副本任务不能替代二转试炼。只有角色职业变成选定的二转职业，才算完成；任务完成提示、达到30级或获得经验都不够。

先查看角色职业、任务记录和背包：仍是一转职业时，按照下方对应职业路线继续；如果已经是二转职业，停止重复接转职任务。遇到菜单、任务名称或目标与本篇不符时，记录实际名称和任务编号，不要猜测同一 NPC 的其他任务就是二转，也不要靠继续升级解决。

## 出发前

- 准备药水、武器及职业所需弹药，给背包其它栏留空位。
- **先选好分支**：转职后的路线将影响三转、四转，最终确认前核对名称。

| 一转职业 | 一转导师 | 二转选择 |
| --- | --- | --- |
| 战士 | 勇士部落的武术教练 | 剑客、准骑士、枪战士 |
| 魔法师 | 魔法密林的汉斯 | 火毒法师、冰雷法师、牧师 |
| 弓箭手 | 射手村的赫丽娜 | 猎人、弩弓手 |
| 飞侠 | 废弃都市的达克鲁 | 刺客、侠客 |
| 海盗 | 诺特勒斯号的凯琳 | 拳手、火枪手 |

## 战士、魔法师、弓箭手、飞侠：传统考试

1. 30级后找上表的一转导师，接受二转考验并取得推荐信。
2. 找本系的二转教官，交信进入考场。教官并不在一转导师身边；具体位置以游戏内地图和对话为准。
3. 在考场打怪，收集 **30个黑暗弹珠（4031013）**。找考场内教官交付，领取**英雄的证明（4031012）**。脚本会收走持有的全部该弹珠，交付后检查背包中是否有证明。
4. 回到一转导师处，选择并确认目标分支，交出证明完成转职。查看角色职业和技能栏，确认结果。

| 职业 | 推荐信物品 ID | 二转教官 NPC ID | 考场地图 ID |
| --- | --- | --- | --- |
| 战士 | 4031008 | 1072000 | 108000300 |
| 魔法师 | 4031009 | 1072001 | 108000200 |
| 弓箭手 | 4031010 | 1072002 | 108000100 |
| 飞侠 | 4031011 | 1072003 | 108000400 |

战士教官位于地图 `102020300` 附近；法师教官位于地图 `101020000`。弓箭手与飞侠教官的具体入口位置尚未核实，不建议仅凭考场地图 ID 寻路。

**中断后续做：**先查看任务、背包中的信件或证明，再与相关导师、教官对话；不要假定断线或死亡后考试进度保留。弓箭手导师脚本存在信件检查与发放 ID 不一致的情况，中断后提示可能异常，需以现场情况为准。

## 海盗：独立试炼

海盗不套用上面的30弹珠流程。30级后找凯琳，接取对应二转任务，再由凯琳送入考场；若考场有人，脚本会提示稍后再试。完成所选任务后回凯琳处转职。

| 目标 | 任务 ID | 任务名称参考 | 考场地图 ID |
| --- | --- | --- | --- |
| 拳手／格斗家 | 2191 | 成为拳手的途径 | 108000502 |
| 火枪手／枪手 | 2192 | 成为火枪手的途径 | 108000501 |

上述名称来自外部冒险岛任务数据库，北斗客户端显示名称尚未核实；名称有差异时以任务 ID 和凯琳的实际二转对话核对。具体操作：① 在诺特勒斯号与凯琳对话，选择所需分支的二转任务，核对 ID；② 再按凯琳对话进入对应考场，按该任务说明完成目标；③ 找凯琳交任务并确认所选职业；④ 检查角色职业确实变为拳手或火枪手。凯琳提供的其他任务不属于上述两项，不要以它们的完成状态代替二转。

**只完成自己想选的那一项。**脚本在两项都完成时会随机选择拳手或枪手，存在选错职业的风险。任务的具体目标和数量尚未核实，请以游戏内任务说明为准；不要将其他版本的材料数量当成北斗规则。
