# 主题地图任务升级推荐

想做任务练级，先走 **30级蘑菇王城 → 35级废都广场**；之后按所在地区和可接等级选一条，不用清遍所有地图。

适用北斗 V17，以下为静态资料推荐，**尚未试玩或测算效率**。经验是标称奖励，不保证实际到账或能升几级；“推荐等级”也不等于准入条件。

## 优先考虑

### 蘑菇王城：推荐30～38级，二转后出发

30～50级、已二转时接 **危机中的蘑菇王国**，同意传送，带推荐书找警卫队长；自行去则走射手村西侧大树方向。沿 **勇士考试 → 探索森林／越过城墙 → 阻止婚礼／解救公主 → 显露的真相** 做，适合二转起步，收尾有35级 **蘑菇王的皮手套**（基础物攻+1、魔攻+2）。35级可转废都广场，卡Boss也可以先走；刷1500只怪的“企鹅王的卷轴”偏奖励目标，不建议专为升级做。

### 废都广场：35～50级接取

废弃都市地铁站找 **冬青** 接 **阿赫的愿望**，检票口选废都广场，到站找阿赫，跟 **拉娜的演出筹备 → 摇滚之魂 → 演出准备完成** 推进。后段两项标称48500、37200经验，收尾有 **自由灵魂之戒**（名称如此，实际是45级耳饰）。拿完奖励转童话村、玛加提亚或50级后的武陵／百草堂，不必卡着Boss硬做。

### 阿里安特：推荐24～35级

天空之城乘船去阿里安特，先找 **巴一岚** 做 **学习阿里安特的文化**。24级看舞姬线、27级看“沙子图团员的请求?!”、29级看秘密组织线；后段有经验、药品及鞋子跳跃卷轴。适合边逛沙漠边做，30级先办二转，再选蘑菇王城或邻近的玛加提亚，不必补齐跨城支线。

### 童话村：37级故事、45级斧头、60级鬼怪

从玩具城东侧 **赫丽奥斯塔 → 图书馆** 去童话村。37级找 **小荳** 做瓮／艾蒿／木锄头线，三项标称合计48000经验；故事书拿回图书馆找 **威兹** 交对应整理任务，还能再领奖。45级看“金银斧”，60级看“消灭鬼怪”（准备加击退标称合计80000经验）。一段做完就换图，不用等齐所有故事。

### 玛加提亚：35级入门，52～75级分段回来

从阿里安特沿沙漠过去，找 **后街小贩** 开两协会任务。35级做贝丁／罗赛伦研究，52级接后续，55／60级做 **琦尼的洛伊德／氯化洛伊德研究**（标称43000／48900经验），70～75级再追德朗博士。下一段等级不到就先去别处；75级“为了琵丽雅”标称120000经验，但三个结局互斥，要先选想要的奖励。

### 武陵：50级修炼，71／77级补Boss支线

天空之城码头找 **鹤** 去武陵，到寺院找 **诺功、道功**。50级诺功三轮教导标称合计48000经验；71级韩太守线的“击倒肯德熊”标称215400，77级妖怪禅师线的击退任务标称278700。普通任务做完可接百草堂；Boss留到能稳定打过再回来，不为经验提前硬打。

### 百草堂：推荐50～70级

武陵寺院找 **鹤** 转百草堂。找 **邱老头** 做50级“药草地的入侵者1、2”（标称合计51800经验），49级起也可看“击退逃出的罐子”（44600经验）。适合当地狩猎时一起交；55级后的海盗任务涉及组队场景，单人不必全清，交完可转新加坡或玛加提亚。

### 新加坡：58级开线，63级接后段

**导游妮妮 → 驳船码头城**，找 **拉尔夫的流浪者**，沿 **过去的秘密 → 前往海洋 → 揭露惊天秘密 → 为未来而战** 做。最后一项标称100000经验＋100000金币，需击败幽灵船长并交材料。适合在幽灵船练级时顺做；打不过船长就先停，转玛加提亚或马来西亚。

### 马来西亚：50／57／60级分批做

**导游妮妮 → 吉隆大都市**，郊外找 **村长玛乐** 做“艳阳高照的一天”起的四项，标称合计90000经验＋26000金币；57级找 **志伟** 做猫咪／轮胎线，60级看 **娜妮** 的围巾线。去甘榜村可找奥黛丽。材料与狩猎目标重合就做，交完换图；90级“前往梦幻主题公园”偏Boss准备，另按战力考虑。

### 时间神殿：90级起，按战力逐段推

走神木村变龙航路到 **三个门** 找 **神殿管理人**，90级开“过去之路”，91级才能接第一轮狩猎。沿 **追忆 → 后悔 → 忘却** 开图，多轮要求999只指定怪，首轮标称189700经验。适合边练边解锁地图；清怪慢或等级未到就暂停。骑士团有单独的120级忘却分支，终段等级别照搬其他职业。

## 顺路选择与暂不推荐项

| 地区 | 指路与取舍 |
| --- | --- |
| **新叶城，36级起** | 废都地铁买票、检票口选新叶城，找 **约翰·贝瑞加德** 做“苏白尼的遗物”（36／38／44级三段）。首段有手套攻击卷轴60%；适合拿奖励，后段不必为升级硬刷材料 |
| **黄金海滩，35／55级** | 明珠港找 **帕森**，到海滩找 **丽尔**。35级特色菜材料多，优先级低；55级巨居蟹线的击退任务标称133500经验，能做完前置和Boss再去。这是旧版黄金海滩 |
| **上海，30／45级** | **妮妮 → 上海外滩**。30级看摄影师赵／杨叔叔的照相机线，45级看暴躁家畜到秘密任务；偏游览顺做，收材料较多，末段奖励有随机项 |
| **艾琳森林／毒雾森林** | 玩具城赫丽奥斯塔100楼时空通路进入；毒雾森林找 **艾琳**。任务资源登记45～55级；入口脚本默认44～55级、4～6人、仅冒险家，配置可放宽人数与等级。战神63级剧情是职业专属，不作为通用单人升级线 |
| **泰国金庙、少林寺等** | 地图资源存在，但尚未核实足够的通用任务链与收益，暂不作任务升级推荐；也不套用其他版本的克里塞、金海滩等路线 |
