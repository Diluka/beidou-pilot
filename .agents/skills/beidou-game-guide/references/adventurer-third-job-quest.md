# 冒险家三转任务攻略

冒险家到70级后，可以找雪域长老接受力量与智慧试炼，完成三转。这篇攻略覆盖北斗 V17 冒险家五系、12条分支；转职后的技能分配见[三转加点规划](adventurer-third-job.md)。骑士团和战神走各自的转职任务。本文按源码与本地资料整理，尚未逐职业试玩，来源见文末。

流程是：准备材料 → 找本职业的长老 → 回金银岛打导师分身 → 圣石答题 → 回长老转职。北斗另有[快速转职入口](#北斗的快速转职入口)，希望体验传统任务时按正文走。

## 出发前准备

- **等级至少70，已完成二转**。三转沿既有分支晋升，不能在此重新选择剑客／准骑士、火毒／冰雷等方向。对话中的旧译名可能不同，可以对照下表找到自己的职业。
- 先完成[二转加点](adventurer-second-job.md)。长老要求剩余SP不超过 `(当前等级 − 70) × 3`：70级时要用完已有SP，71级时最多留3点。超过70级才来转职的角色，按这个数量留点即可，无需把所有SP都花掉；AP不受此限制。
- 带足HP／MP药、解除异常的补给，以及本职业所需箭矢、飞镖或子弹；修好装备。分身试炼有**20分钟**限时，从进入水晶通道开始计时，包含走到分身房的时间。
- **至少准备1颗黑暗水晶（4005004）成品**，并给其它栏留空位；不是黑暗水晶母矿（4004004）。每次开始圣石答题扣1颗，答错或扣除后退出都需另备一颗重来。
- 若只有母矿，雪域的**伯坚（2020000）**提供水晶合成：配方是 **10个黑暗水晶母矿＋100万金币 → 1颗黑暗水晶**。合成前再看一眼对话中的材料和费用。
- 要在金银岛与冰峰雪域之间往返，记得留旅费。下面从冰峰雪域的**长老公馆（211000001）**开始。

## 第一步：向雪域长老接受试炼

在长老公馆找本系长老，选“我想进行第三次职业转职”，同意接受力量与智慧的考验，并读完后续说明。另一项“扎昆地牢任务”是别的内容。

把对话读到长老让你去找金银岛导师，再出发。只打开转职菜单，还没有接下试炼。

## 第二步：击败分身，换取力气项链

1. 回金银岛找上表的本系导师，继续三转考验对话，读完分身说明。完成这一步后才去异界之门；跳过导师直接找门通常没有反应。
2. 在本系地图与异界之门对话，进入限时的水晶通道，再走到右端入口进入分身房。五系的房间分别为战士 `108010301`、法师 `108010201`、弓箭手 `108010101`、飞侠 `108010401`、海盗 `108010501`。
3. 击败对应导师的分身，**捡起黑符（4031059）**。离开前打开背包，看看其它栏里是否已经拿到，别把黑符落在地上。房间会持续扣血，打怪和捡东西时都留意HP。
4. 找房内的**闪耀的水晶（1061010）**确认离开，返回本系入口地图；也可在需要放弃时用它退出。拿到黑符后再离开，避免白打。
5. 再找金银岛导师交黑符，获得 **力气项链（4031057）**。注意北斗资源用的是“力气项链”，部分旧攻略称“力量项链”。
6. 返回长老公馆找本系长老，提交力气项链并读完智慧试炼说明。项链被收走后，才取得圣石答题资格。

这段要跑两趟导师：先听分身试炼的说明，打完分身后再回来换项链，最后交给雪域长老。部分对话会写错下一位长老的名字，例如法师、弓箭手文本中出现艾瑞克；**按职业表找本系长老**即可。

## 第三步：去雪原圣地回答五题

前往**冰雪峡谷Ⅱ（211040200）**找**杰夫（2030000）**，正常进入深处的条件是至少50级，三转角色已满足。对话进入**尖锐的绝壁Ⅰ（211040300）**，继续到**尖锐的绝壁Ⅱ（211040400）**，在右侧上部的隐藏入口 `in00` 进入**雪原圣地（211040401）**，找**神圣的石头（2030006）**。沿途有怪物及冰雪环境扣血；圣地没有普通怪物，也仍需照看HP。

与石头对话时应已让长老收走力气项链、没有持有智慧项链、持有黑暗水晶成品，并有其它栏空位。确认开始后扣1颗水晶，连续答对 **5题**，得到 **智慧项链（4031058）**。

**每次从39题中随机出5题，题目不重复，选项顺序也随机；按答案文字选，不按第几个选项选。**第四、第五题的标题都写作“第四个问题”，答完五题、拿到智慧项链后才算完成。答错会结束答题，已扣的水晶不退，重新对话要从头答五题。

## 第四步：回长老完成三转

带智慧项链回长老公馆，找本系长老确认三转。剩余SP符合要求后，长老会收走智慧项链，把你转成对应的三转职业。

完成后打开角色信息和技能栏，就能看到新职业与三转技能页。通常还会得到 **1 SP、5 AP**；如果服务器开了转职补点，SP可能更多。这里的“技能书”指角色技能页，无需另买道具。接下来看[三转加点规划](adventurer-third-job.md)分配技能。

## 中断、失败或NPC没反应时

先看看自己已经拿到哪件证明道具，通常可以接着上一步做，不用从头开始。

| 遇到的问题 | 接下来怎么做 |
| --- | --- |
| 到异界之门没有反应 | 看看是否到了本系的入口地图，是否先找过雪域长老、读完金银岛导师的分身说明；已经拿到黑符的话，直接回导师交付 |
| 提示已有玩家挑战 | 等当前挑战结束再试。如果提示挑战已关闭，需要请服务器维护者确认是否开放 |
| 分身试炼超时或主动退出，尚无黑符 | 补好药水，再找本系异界之门重试。断线会结束挑战，重连后先看看自己在哪张图、是否已经捡到黑符 |
| 已有黑符 | 先回金银岛导师换力气项链，不必再次打分身 |
| 已有力气项链 | 回本系雪域长老提交，不直接拿它找圣石 |
| 长老已收力气项链，圣石不出题 | 检查是否已持智慧项链、是否带水晶成品、其它栏是否有空位；只有母矿不够。条件都满足仍没反应的话，带着对话提示询问服务器维护者，通常不用重打分身 |
| 答错或扣水晶后关闭对话 | 重新备1颗成品水晶，再找圣石，从头答五题；不用重新打分身 |
| 已有智慧项链 | 直接回本系雪域长老完成三转；SP不符合要求时先按等级检查可留点数，无需重新答题 |
| 证明道具丢失，或对话与本篇明显不符 | 补发方法暂不明确，先保留其他证明道具，向服务器维护者说明丢了什么、卡在哪一步，别急着重买材料 |

三转进度会随长老和导师的对话保存，有些步骤不一定显示在普通任务栏里。卡住时，优先看对话提示和背包中的证明道具，按上表继续。

## 北斗的快速转职入口

想直接转职，可以打开拍卖行看看是否进入 **BeiDou脚本中心 → 快速转职**。入口取决于服务器设置；如果打开的是原拍卖系统，就没有这个菜单，可以继续走传统试炼。

已经二转且至少70级的冒险家，可以沿现有分支直接三转，无需黑符、项链或黑暗水晶，也不受传统长老的剩余SP限制。确认后打开角色信息和技能栏查看新职业。若已经开始传统试炼，快速转职不会替你补完那段剧情，已有任务和证明道具也不一定会自动清理。
