# 冒险家三转任务攻略

适用范围：北斗 V17 冒险家五系、12条二转分支，目标是完成70级传统三转试炼。2026-11-11 依据固定公开北斗源码整理，并交叉核对本地 V17 相关地图与道具名称；**本篇尚未逐职业实际走通**，不代表常驻服当前配置或现场结果。骑士团和战神不适用。转职后的配点见[三转加点规划](adventurer-third-job.md)。

阅读顺序：准备材料 → 查本职业的长老与分身入口 → 完成力量试炼 → 圣石答题 → 回长老转职。北斗另有[快速转职入口](#北斗的快速转职入口)，希望体验传统任务时按正文走。

## 出发前准备

- **等级至少70，已完成二转**。三转沿既有分支晋升，不能在此重新选择剑客／准骑士、火毒／冰雷等方向。下表列出准确职业ID，避免被对话中的旧译名误导。
- 先核对并完成[二转加点](adventurer-second-job.md)。传统长老最终接受的剩余SP上限为 `(当前等级 − 70) × 3`：70级时必须用完已有SP，71级时最多留3点；不要因提示“用完所有SP”就把延迟转职期间的点数也盲目花掉。AP不在这个检查中。
- 带足HP／MP药、解除异常的补给，以及本职业所需箭矢、飞镖或子弹；修好装备。分身试炼有**20分钟**限时，从进入水晶通道开始计时，包含走到分身房的时间。
- **至少准备1颗黑暗水晶（4005004）成品**，并给其它栏留空位；不是黑暗水晶母矿（4004004）。每次开始圣石答题扣1颗，答错或扣除后退出都需另备一颗重来。
- 若只有母矿，雪域的**伯坚（2020000）**提供水晶合成：脚本配方为 **10个黑暗水晶母矿＋100万金币 → 1颗黑暗水晶**。这是固定源码中的费用，付款前看清现场确认框；本篇没有核验当前交易价格、掉率或更便宜的获取途径。
- 规划好金银岛与冰峰雪域之间的往返。正文从冰峰雪域的**长老公馆（211000001）**开始；不预设所有服务器都有免费传送。

## 第一步：向雪域长老接受试炼

在长老公馆找本系长老，选“我想进行第三次职业转职”，同意接受力量与智慧的考验，并读完后续说明。另一项“扎昆地牢任务”是别的内容。

完成后长老应让你去找金银岛导师。此时仅到达70级、只打开过菜单或去过金银岛，都不等于已取得分身试炼资格。

## 第二步：击败分身，换取力气项链

1. 回金银岛找上表的本系导师，继续三转考验对话，读完分身说明。完成这一步后才去异界之门；跳过导师直接找门通常没有反应。
2. 在本系地图与异界之门对话，进入限时的水晶通道，再走到右端入口进入分身房。五系的房间分别为战士 `108010301`、法师 `108010201`、弓箭手 `108010101`、飞侠 `108010401`、海盗 `108010501`。
3. 击败对应导师的分身，**拾取并确认其它栏中已有黑符（4031059）**。打倒分身、看到掉落或倒计时仍在，均不能替代背包核对。房间有环境扣血，战斗及拾取时留意HP。
4. 找房内的**闪耀的水晶（1061010）**确认离开，返回本系入口地图；也可在需要放弃时用它退出。拿到黑符后再离开，避免白打。
5. 再找金银岛导师交黑符，获得 **力气项链（4031057）**。注意北斗资源用的是“力气项链”，部分旧攻略称“力量项链”。
6. 返回长老公馆找本系长老，提交力气项链并读完智慧试炼说明。项链被收走后，才取得圣石答题资格。

结果核对：黑符 → 力气项链 → 长老收走项链，三步按顺序完成。部分导师对话把下一位长老写成了别系NPC，例如法师、弓箭手文本中出现艾瑞克；**以职业表回本系长老**，不要跟着错译跨系交付。

## 第三步：去雪原圣地回答五题

前往**冰雪峡谷Ⅱ（211040200）**找**杰夫（2030000）**，正常进入深处的条件是至少50级，三转角色已满足。对话进入**尖锐的绝壁Ⅰ（211040300）**，继续到**尖锐的绝壁Ⅱ（211040400）**，在右侧上部的隐藏入口 `in00` 进入**雪原圣地（211040401）**，找**神圣的石头（2030006）**。沿途有怪物及冰雪环境扣血；圣地没有普通怪物，也仍需照看HP。

与石头对话时应已让长老收走力气项链、没有持有智慧项链、持有黑暗水晶成品，并有其它栏空位。确认开始后扣1颗水晶，连续答对 **5题**，得到 **智慧项链（4031058）**。

**题目从39题中随机抽取且本轮不重复，选项顺序也随机；按答案文字选，不按第几个选项选。**脚本标题把第四、第五题都写作“第四个问题”，不要因此提前退出；以拿到智慧项链为准。答错会结束本轮，不返还已扣水晶，重新对话从头答五题。

## 第四步：回长老完成三转

带智慧项链回长老公馆，仍找本系长老，确认三转。通过SP检查后收走智慧项链，职业ID由既有二转ID加1，得到表中的三转职业；不再重新选分支。

完成后核对角色资料的职业、三转技能页和新增点数。固定源码中冒险家三转通常奖励 **1 SP、5 AP**，SP会受转职补点配置影响，应以角色实际变化为准。这里说的“技能书”是角色技能页，不是要求另买道具；三转加点与四转前置继续看[三转加点规划](adventurer-third-job.md)。

## 中断、失败或NPC没反应时

先看职业与背包，按已经取得的成果继续，不从第一步反复重接。

| 当前情况 | 继续方式／停止条件 |
| --- | --- |
| 到异界之门没有反应 | 核对地图、本系二转职业，先找雪域长老接三转，再把金银岛导师的分身说明读完；持有黑符时门本来就不再放行 |
| 提示已有玩家挑战 | 等当前挑战结束再试；事件未配置时会提示关闭，这是环境问题，停止反复点击 |
| 分身试炼超时或主动退出，尚无黑符 | 检查补给与资格，再找本系异界之门重试；断线会结束该事件，恢复后先确认地图和背包 |
| 已有黑符 | 先回金银岛导师换力气项链，不必再次打分身 |
| 已有力气项链 | 回本系雪域长老提交，不直接拿它找圣石 |
| 长老已收力气项链，圣石不出题 | 检查是否已持智慧项链、是否带水晶成品、其它栏是否有空位；只有母矿不够。仍无反应时保留当前状态，核对实际脚本版本，不盲目重打分身 |
| 答错或扣水晶后关闭对话 | 重新备1颗成品水晶，再找圣石，从头答五题；不用重新打分身 |
| 已有智慧项链 | 直接回本系雪域长老完成三转；SP不符合要求时先按等级检查可留点数，无需重新答题 |
| 证明道具丢失，或对话与本篇明显不符 | 本次未核实补发途径；停止丢弃、重接或购买更多材料，记录职业、地图、道具和提示，交由维护者核对 |

这些阶段由脚本保存内部标记 `JB3`（已受长老委托）、`JBP`（已与金银岛导师确认力量试炼）、`JBQ`（已提交力气项链）推进，不宜仅凭普通任务面板有没有任务来判断。玩家无需编辑这些标记，也不要改数据库补进度。

## 北斗的快速转职入口

只想取得三转职业、无需完成传统试炼时，可以先查看拍卖行是否打开 **BeiDou脚本中心 → 快速转职**。固定源码在关闭原MTS功能（`use_mts=false`）时，将拍卖行入口接到脚本中心；该菜单包含普通玩家可见的“快速转职”。**这不保证每个部署都有相同入口**；如果现场打开的是原拍卖系统，先核对配置，不按截图猜按键。

对于表中的二转冒险家，快速转职脚本要求至少70级，并沿现有职业转为ID加1；这一分支不要求黑符、两条项链、黑暗水晶或传统长老的剩余SP检查。操作前仍核对职业、等级及自己的加点计划，确认后检查职业和技能页。快速转职不等于完成了力量、智慧两段试炼；已在传统路线中的角色也不能把快速转职当作自动清理旧任务和道具的保证。

- [基础地图目录][maps]：公馆位于 `Map2/211000001.img.xml`；五系门在 `Map1` 下的表列地图；圣地路线在 `Map2/211040200、211040300、211040400、211040401.img.xml`。读取 `life`、`portal`、`info/decHP`；地图名称与道具名见[中文String资源][strings]的 `Map.img.xml`、`Npc.img.xml`、`Etc.img.xml`。
- [快速转职脚本][quick]和[脚本中心9900001][center]；[拍卖入口处理器][mts]中的 `use_mts`、`openCenterScript` 决定入口是否替换。[Character.changeJob][character]决定转职点数与属性增益；[脚本加载规则][loader]说明中文覆盖优先级。

后续现场核验应在授权的专用角色和隔离目标中进行：每系至少观察接取 → 击败分身并拾取黑符 → 两次项链交付 → 五题答对 → 职业ID变化；另分别观察超时续做、答错重新扣水晶、SP阻止转职后继续。五系共用入口与脚本不等于12个职业均已走通；未观察的分支继续保留未实测状态。
