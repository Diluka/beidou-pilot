# 一转后的职业任务攻略

本篇整理北斗 V17 一转后的职业训练与剧情，按职业找对应章节；任务条件还允许部分进阶职业接取，不以“一转”字样代替实际条件。这里的“一转任务”是转职之后的任务，不是转职考试。资料来自固定版本资源和脚本，尚未逐职业试玩；实际提示与当前服务器设置有差异时，以任务栏和现场结果为准。

## 五系基础修炼

冒险家战士、魔法师、弓箭手、飞侠、海盗分别找自己的金银岛导师。对应骑士团职业也在任务职业条件内：魂骑士、炎术士、风灵使者、夜行者、奇袭者分别对应下表五行；战神也可做战士这一行。每轮先接任务，完成击杀后回表中导师交付，再接下一轮。任务的接取等级上限为 **40级**；四轮分别登记任务编号，不是一次累计击杀数量。

| 职业系／导师 | 任务编号，按顺序 | 各轮目标 |
| --- | --- | --- |
| 战士／勇士部落武术教练 | 2128、2129、2130、2131 | 木妖 `130100` 20、50、80只；黑木妖 `1110101` 15只 |
| 魔法师／魔法密林汉斯 | 2132、2133、2134、2135 | 绿水灵 `210100` 8、20、35只；黑木妖 `1110101` 10只 |
| 弓箭手／射手村赫丽娜 | 2136、2137、2138、2139 | 绿水灵 `210100` 16、40、65只；漂漂猪 `1210101` 15只 |
| 飞侠／废弃都市达克鲁 | 2140、2141、2142、2143 | 木妖 `130100` 20、50、80只；三眼章鱼 `1120100` 10只 |
| 海盗／诺特勒斯号凯琳 | 2193、2194、2195、2196 | 猪猪 `1210100` 11、26、43只；指定绿蘑菇 `9101000` 10只 |

海盗最后一轮的指定绿蘑菇与普通同名怪物可能不是同一个目标，先接任务并观察计数。任务资源的基础经验：法师四轮依次为290、323、345、470；其他四系依次为590、610、645、840，实际经验受服务器倍率影响。资源还列有药水和回城卷奖励；海盗奖励存在职业位掩码，奇袭者是否能拿到相同物品需以实际结果为准。

## 五系修炼后的职业剧情

完成上表第四轮后，找同一导师开启各自的剧情链。任务资源允许对应骑士团职业接取，战士线也列入战神；各链还允许进阶职业，入口前置修炼的接取上限是40级，剧情链本身没有同样的等级上限字段。每一项以任务栏编号、当前目标和NPC提示为准，先接再打；以下材料以任务条件为依据，个别道具的获取点尚待实测。

| 职业 | 剧情路线与重点 |
| --- | --- |
| 战士，28162～28179 | 武术教练介绍培训导师 `9201119`；完成并行训练：黑木妖30只、木柴 `4000005` 20个。报告后到废都查水管，在 `102040000` 击打消防栓取 `4001340` 3个，再打绿水灵30只。射手村调查斯坦遇袭：准备 `4001343` 15个、`4001344` 10个、`4001345` 1个，打怪找线索 `4001341`；赴诺特勒斯调查并按任务制作酒，再去魔法密林追查。最后接28179，持徽章 `4032491`，从 `102020300` 暗门进入，击败印第安老斑鸠 `9400609` 后交任务 |
| 法师，28180～28198 | 汉斯介绍露西；完成绿水灵30只、绿液球20个、木妖30只、树枝20个四项训练并报告。找凯琳打猪猪30只、漂漂猪20只；射手村配感冒药需花蘑菇盖20个、蝴蝶结10个、绿水灵珠 `4000010` 2个。废都调查病毒时打三眼章鱼和花蘑菇各30只并收集标本；勇士部落再打黑木妖、斧木妖各30只。28198进行中持 `4032495`，从 `101010103` 暗门进入，击败牛魔王 `9400612` |

| 海盗，28239～28256 | 凯琳介绍木拉特；完成漂漂猪30只与蝴蝶结20个两项训练并报告。解读藏宝图需要分阶段收集绿液球20个、猪肉 `4001357` 20个，打黑木妖30只，以及后续地图、墨水等任务材料；到射手村找 `4001363` 与 `4001362` 各1个，返回诺特勒斯追查雪之猫女。地下室箱子取得徽章 `4032494`；28256进行中持徽章从 `100030000` 暗门进入，击败雪之猫女 `9400611`。任务叙述与交付NPC条件有差异，交付时以任务栏和实际提示核对 |

这些剧情中的培训与材料常是多个任务并行；缺下一项时先查看已接任务、道具及同阶段未完成的训练。弓箭手复苏弓的文字还提到 `1452083`，但静态完成条件和奖励没有列出它，实际要求尚待验证。

## 骑士团剧情与派遣

魂骑士、炎术士、风灵使者、夜行者、奇袭者共用训练和派遣线。10～15级可从南哈特接“可以这样出去吗？”（20700），找奇库完成三轮实地训练；13级起按等级逐步完成金银岛派遣。各段步骤、怪物数量、特殊物品及人偶师暗号统一看[骑士团新手任务：一转后](cygnus-newbie.md#一转后实地适应训练与派遣任务)，其中亦标出任务叙述与计数差异。

## 战神：修炼与情报搜集

一转后从利琳接“新的开始”（21700），分配完全部AP，再到里恩村左侧入口找普奥交付。脚本给的是矛 `1442000`；普奥直接开启下一项。21701～21703依次击杀修炼用绿水灵 `9300341`、花蘑菇 `9300342`、猪猪 `9300343` 各30只；最后一轮脚本解锁连击技能上限。再按任务栏做21704，13级后继续情报线。

| 等级／任务段 | 做法 |
| --- | --- |
| 13级，21705～21712 | 去金银岛找明珠港特鲁，再找特奥；21707收集绿、蓝、红蜗牛壳各10个。到射手村找布鲁斯，依次交花蘑菇角30个、猪尾巴50个；21711击杀玩世不恭的花蘑菇 `9300274` 50只并取得人偶 `4032315` 1个，回报结束第一次情报搜集。21766／21767是木箱调查分支 |
| 18级，21713～21716 | 找魔法密林妖精罗雯：21714击杀绝望绿蘑菇 `1110130` 25只并取得人偶 `4032316`；21715调查会说话的树，再完成报告。21717、21718是19、20级的罗雯支线，各击杀指定绿蘑菇 `9101000` 100只并分别取得人偶 `4032317`、`4032318` |
| 22～25级，21719～21725 | 接21719会立即完成并传送，继续21720；23级起找勇士部落布吉调查。21722的条件是古木妖 `9101002` **100只**，叙述写200只；21723到 `101030101` 打遗迹取得人偶 `4032319` 5个。完成21724；21725为布吉支线 |
| 28～29级，21726～21732 | 找林中之城日吉：21727击杀僵尸蘑菇 `9101001` **300只**并取得人偶 `4032321`；21728调查火独眼兽洞穴入口，再回报。进行21729时找奇怪的石像，21730交火独眼兽尾100个。21731的人偶师目标为 `9300344` 1只与文件 `4032322` 1份；21732带文件 `4032341` 回利琳 |

人偶师入口暗号为 **弗朗西斯是天才傀儡师！**，包含全角叹号。入口检查的击杀 ID 与任务要求不同，相关刷怪地图与入口地图的衔接尚未实测；卡住时记录任务状态、当前地图和提示，不能假定可直接重入或已完成。
