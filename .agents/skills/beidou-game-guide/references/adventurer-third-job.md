# 冒险家三转加点规划

这篇攻略列出北斗 V17 冒险家12条三转分支在120级、四转前的最终加点，并为后续四转留好技能前置。尚未转职时先看[三转任务攻略](adventurer-third-job-quest.md)。配点按技能资料整理，尚未逐职业试玩，来源见文末。

先按[二转攻略](adventurer-second-job.md)确认分支与武器，再看本篇对应表格。表中数字均为**最终技能等级**；已有投入的角色只补差额，不再追加同样数量。技能名称采用本版本中文资源，同名或名称相近时以技能ID区分。

## 三转有多少技能点

以70级及时三转、升级每级3 SP为基准：三转奖励1点，71～120级共50次升级获得150点，合计 **151 SP**。这些点数对应120级升级后、四转前，四转奖励点另算，二转已经花过的121点也另算。如果延迟过转职、拿过赠点，或服务器设置不同，先算清自己的已花点数和剩余SP。

推荐方案优先保留常用攻击、移动和辅助技能，武器技能只点所选路线，表中的0表示这套方案舍弃了该项。偏重防御、控制或其他打法时，可以采用文中的换点办法；自己调整时，留意前置和151点总数。

**三转技能无需技能书或能手册**，满足前置后直接花SP提升。四转阶段顺序见[四转加点攻略](adventurer-fourth-job.md)，书籍与解锁入口见[独立获取指引](fourth-job-skillbooks.md)。

## 战士

### 剑客 → 勇士（111）→ 英雄

以**剑**为推荐方案；斧路线将狂乱之剑、气绝剑的投入分别换到狂乱之斧、气绝斧，其他不变。沿用二转选定的武器，不双修两套消耗斗气的攻击。

| 技能 | 终态等级 |
| --- | ---: |
| 斗气集中 | 30 |
| 狂乱之剑 | 30 |
| 气绝剑 | 30 |
| 虎咆哮 | 21 |
| 防御崩坏 | 20 |
| 魔力恢复 | 20 |
| 盾防精通 | 0 |
| 狂乱之斧、气绝斧 | 0 |
| **合计** | **151** |

保留单体、群体斗气攻击与解除物防提升的能力，虎咆哮承担补充控制。狂乱、气绝均需斗气集中1级，防御崩坏需虎咆哮3级。**斗气集中必须30级**，为四转进阶斗气保留前置。

盾防精通提高盾牌的防御力。用单手武器搭配盾牌时，可以把魔力恢复20换成盾防精通20，总数仍151；用双手武器就按上表加。

### 准骑士 → 白骑士（121）→ 圣骑士

以**剑**为推荐方案；钝器路线将三种剑属性技能分别换到对应钝器技能，属性攻击等公共项不变。

| 技能 | 终态等级 |
| --- | ---: |
| 属性攻击 | 30 |
| 烈焰之剑 | 30 |
| 寒冰之剑 | 30 |
| 雷电之击：剑 | 30 |
| 魔力恢复 | 20 |
| 魔法崩坏 | 11 |
| 盾防精通 | 0 |
| 烈焰钝器、寒冰钝器、雷电之击：钝器 | 0 |
| **合计** | **151** |

保留所选武器的火、冰、雷三种属性，打不同怪物时选择合适的一种。魔法崩坏需属性攻击3级；**属性攻击必须30级**，是四转万佛归一破的前置。本版本的寒冰属性技能上限也是30，按表加满即可。

持盾路线可将魔力恢复20换成盾防精通20。若更重视解除怪物魔防提升，可将魔法崩坏改20、魔力恢复改11，总数仍151；盾防精通维持0。

### 枪战士 → 龙骑士（131）→ 黑骑士

**AI玩家推荐单修，优先按单枪方案规划。**固定使用枪，以枪连击处理较少目标、无双枪处理群怪，不需要在战斗中切换武器；若已有合适的矛，也可选单矛方案。双修保留枪连击与无双矛的搭配及两类装备的选择空间，适合能稳定完成切武器、切对应技能的玩家。

| 技能 | 单枪（AI推荐） | 单矛 | 枪矛双修 |
| --- | ---: | ---: | ---: |
| 枪连击 | 30 | 0 | 30 |
| 矛连击 | 0 | 30 | 0 |
| 无双枪 | 30 | 0 | 0 |
| 无双矛 | 0 | 30 | 30 |
| 龙之献祭 | 3 | 3 | 3 |
| 龙咆哮 | 30 | 30 | 30 |
| 龙之魂 | 20 | 20 | 20 |
| 魔法抗性 | 20 | 20 | 20 |
| 力量崩坏 | 18 | 18 | 18 |
| **合计** | **151** | **151** | **151** |

三种方案的公共技能相同，区别是将60点攻击预算放到哪两项技能。单修不用频繁切换武器和技能；双修需要准备两把武器，并在枪连击前装备枪、无双矛前装备矛。使用AI控制角色时，建议选单修，减少切换失误。

即使二转按[枪矛双修支持表](adventurer-second-job.md#枪战士--龙骑士--黑骑士)投入，三转仍可选择单修；二转学过两类武器支持，不代表战斗中必须轮换使用。

龙咆哮需龙之献祭3级，力量崩坏需龙之魂3级。献祭、咆哮和龙之魂都会消耗HP，练级时留意血量并备好药水。三种方案都把献祭留在前置要求的3级，将余点留给抗性与崩坏。

## 魔法师

### 火毒法师 → 火毒巫师（211）→ 火毒魔导师

| 技能 | 终态等级 |
| --- | ---: |
| 魔力激化 | 30 |
| 末日烈焰 | 30 |
| 致命毒雾 | 30 |
| 火毒合击 | 30 |
| 魔法狂暴 | 20 |
| 封印术 | 10 |
| 火毒抗性 | 1 |
| **合计** | **151** |

保留火系范围攻击、毒雾与单体合击，支持面对不同属性怪物时切换攻击。封印术、魔法狂暴均需魔力激化3级。魔力激化提高MP消耗，升级它时也要考虑药品供给。

抗性1、封印10是为了保留三种攻击满级的取舍。若更重视辅助和抗性，可将火毒合击改11、封印术改20、火毒抗性改10，总数仍151；代价是降低合击的伤害。三转**致命毒雾（2111003）**与二转**毒雾术（2101005）**分开计算。

| 技能 | 终态等级 |
| --- | ---: |
| 魔力激化 | 30 |

| 落雷枪 | 30 |

| 封印术 | 10 |

保留冰系范围攻击、雷系单体攻击及合击。封印术和魔法狂暴都需要魔力激化3级，耗蓝增加后也要备足药水。

偏重辅助与抗性时，可将落雷枪改11、封印术改20、冰雷抗性改10，总数仍151。两系法师的四转技能资料中，都没有列出直接要求三转技能的前置。

| --- | ---: |

| 圣光 | 30 |

## 弓箭手

### 猎人 → 射手（311）→ 神射手

| 技能 | 终态等级 |
| --- | ---: |
| 箭扫射 | 30 |
| 箭雨 | 30 |
| 贯穿箭 | 20 |
| 替身术 | 20 |
| 疾风步 | 20 |
| 银鹰召唤 | 15 |
| 烈火箭 | 16 |
| **合计** | **151** |

保留单体扫射、范围箭雨、近距离射击与移动辅助，烈火箭作为属性攻击取舍项。箭雨需贯穿箭5级，银鹰召唤需替身术5级；**银鹰召唤至少15级**，是四转火凤凰前置。

这里的贯穿箭（3110001）是三转被动，不是二转弩的穿透箭，也不是四转箭神的穿透箭。使用银鹰召唤要带召唤石。

### 弩弓手 → 游侠（321）→ 箭神

| 技能 | 终态等级 |
| --- | ---: |
| 箭扫射 | 30 |
| 升龙弩 | 30 |
| 寒冰箭 | 21 |
| 贯穿箭 | 15 |
| 替身术 | 20 |
| 疾风步 | 20 |
| 金鹰召唤 | 15 |
| **合计** | **151** |

保留单体、范围和冰系控制。寒冰箭21级在技能资料中的冻结时间已是3秒，与30级相同，因此先留21，把点数分给移动和辅助；30级伤害仍然更高。能否冻结还要看怪物种类。

升龙弩需贯穿箭5级，金鹰召唤需替身术5级；**金鹰召唤至少15级**，为四转冰凤凰保留前置。若希望寒冰箭30，可将疾风步从20改11，其他不变，仍151；先确认能否接受移动收益减少。

## 飞侠

### 刺客 → 无影人（411）→ 隐士

| 技能 | 终态等级 |
| --- | ---: |
| 影分身 | 30 |
| 多重飞镖 | 30 |
| 二段跳 | 20 |
| 药剂精通 | 20 |
| 聚财术 | 20 |
| 影网术 | 20 |
| 金钱攻击 | 11 |
| **合计** | **151** |

保留分身、群攻、移动与药品收益，金钱攻击作为余点项。二段跳需多重飞镖5级，金钱攻击需聚财术5级。偏重金币攻击时，可将金钱攻击改30、影网术改1，总数仍151，代价是降低影网控制能力。

影分身要带召唤石，金钱攻击会花金币；药剂精通不适用于按百分比恢复的道具。

| 技能 | 终态等级 |
| --- | ---: |
| 分身术 | 30 |
| 落叶斩 | 30 |
| 金钱炸弹 | 30 |
| 金钱护盾 | 20 |
| 敛财术 | 20 |
| 转化术 | 3 |

保留主要攻击、金币玩法和护盾；转化术仅留金钱护盾要求的3级，强化盾收尾18。敛财术需金钱炸弹3级。强化盾增加盾牌物理防御，不增加攻击力；不持盾时，可将这18点转给转化术，使其21、强化盾0，总数仍151。

金钱护盾消耗金币，金钱炸弹依赖地面上属于自己的金币；分身术（4211004）也不同于标飞的影分身（4111002）。

## 海盗

### 拳手 → 斗士（511）→ 冲锋队长

| 技能 | 终态等级 |
| --- | ---: |
| 能量获得 | 40 |
| 能量爆破 | 30 |
| 能量耗转 | 11 |
| 眩晕精通 | 20 |
| 超人变形 | 20 |
| 碎石乱击 | 30 |
| **合计** | **151** |

**能量获得上限40，不是30。**推荐方案保留满能量支持、群攻与变形攻击，能量耗转留11。能量爆破、能量耗转均需能量获得1级，碎石乱击需超人变形1级。

四转超能量要求能量获得至少1级；**超级变身要求超人变形20级**。两项都已满足。能量技能要在能量充满后使用，碎石乱击则要等超人变形；变形冷却时换用其他攻击。

### 火枪手 → 大副（521）→ 船长

| 技能 | 终态等级 |
| --- | ---: |
| 三连射杀 | 20 |
| 章鱼炮台 | 30 |
| 海鸥空袭 | 15 |
| 烈焰喷射 | 30 |
| 寒冰喷射 | 26 |
| 导航 | 30 |
| **合计** | **151** |

**一转双弹射击（5001003）要先加到20级**，才能学三连射杀（5210000）。这20点来自之前的一转加点，不包含在三转的151点里；老角色没加满时，要先算好补点会占用多少SP。

推荐方案保留单体、固定炮台、喷射与导航，并满足四转要求：三连射杀20 → 金属风暴，章鱼炮台30 → 超级章鱼炮台，海鸥空袭15 → 地毯式空袭，导航30 → 导航辅助。

寒冰喷射26级在技能资料中已能打6个目标、冻结3秒，与30级相同，但伤害仍低于30；这套方案省出4点用于其他技能。若更偏重海鸥空袭，可改海鸥空袭30、烈焰喷射11、寒冰喷射30，其他不变，仍151。两种喷射要带对应消耗品，遇到Boss也别依赖冻结来保命。

## 四转前容易漏掉的准备

先看上表中本职业的前置，再回头看看二转的精准、急速等技能有没有加够。大副还要检查一转双弹射击20；换走斧、钝器或单枪、单矛路线时，记得对应替换武器技能。

表中的151点只算三转阶段。已经加过点的角色只补差额；点数不够时，先看看有没有用三转SP补旧技能。如果自己的技能上限与表格不同，先留住剩余点数，查清版本差异后再加。

练级前也别忘了补给：召唤技能要带石头，喷射技能要带消耗品，金币技能会花钱；龙骑士尤其要留意献祭、咆哮和龙之魂的耗血。
