# 骑士团新手任务攻略

这篇攻略带你从圣地的贵族新手开始，完成10级一转，再继续一转后的训练与13～28级派遣任务。适用于北斗 V17 骑士团；五个职业的技能分配见[骑士团终态加点](cygnus-skills.md)。路线按任务资源与源码整理，尚未完整试玩，资料版本见文末。

## 先辨认自己的任务线

新建骑士团角色从圣地教学区 `130030000` 出发。见到**奇姆**时，按下节走；旧角色若已经接到“女皇的会面”或“奇库的第一次修炼”，跳到[旧版路线](#旧角色的另一套路线)。两套任务的名称和要求有些相似，按自己任务栏里的那一套做即可。

骑士团的新手职业叫“贵族”（职业1000），出生任务与冒险家的[青苹果乐园路线](newbie.md)不同。青苹果乐园入口只让冒险家新手（职业0）进入。如果你的灯泡里也有“来自北斗开发者的问候”，可以查看对话；骑士团对应的是另一条发放10万金币的分支，是否能接仍以当前任务栏为准。

## 当前出生路线：奇姆到一转

先接任务，再打怪、捡材料、交任务；每交完一项再找下一位。出生教学区主要沿箭头**向左**推进，之后按任务指引到圣地中心、修炼森林。

| 顺序 | 任务与做法 | 奖励与提醒 |
| --- | --- | --- |
| 1 | 找奇姆接 **欢迎来到圣地！（20010）**，向左找奇赞交付 | 通常可得贵族红、蓝药水各5瓶，消耗栏留空位 |
| 2 | 奇赞接 **告诉你狩猎的方法（20011）**，打1只教程解说员提诺，再回报 | 要打的是教程解说员提诺 `9300328`，外形相同的普通提诺 `100120` 不计数；奖励贵族帽、贵族服 |
| 3 | 找奇努接 **你知道技能相关的事情吗？（20012）**，按提示学习、使用贵族攻击技能，打3只提布，并捡1个任务材料 `4000483` | 同时满足击杀与材料，交任务收走材料；不要只打不捡 |
| 4 | 找奇雅接 **这里有装着道具的箱子（20013）**，用**普通攻击**打箱，捡石材 `4032267` 和徽章 `4032268` 各1个 | 交付后得到椅子 `3010060`；这不是打怪任务，技能攻击不能代替敲箱 |
| 5 | 找奇莎接 **女王殿下正在等候你呢。（20014）**，回答教学题，取得初心者证书 `4032269`，带给女皇希纳斯 | 题目答案依次为 **Q、I、3点、一般攻击**；证书交付后消耗 |
| 6 | 若“向年轻女王行礼（20015）”仍可接，则向希纳斯行礼；随后找南哈特做 **你了解黑暗魔法师吗？（20016）** | 交完奇雅的任务后，`20000、20001、20002、20015` 会自动完成；看不到20015时，可以先到“已完成”里找找 |
| 7 | 去修炼森林找奇库，接 **为了成为骑士的第一次训练（20017）**，打15只提姆 `100122`，回报 | 不沿用旧版第一次修炼的“提诺5只” |
| 8 | 奇库接 **为了成为骑士的第二次训练（20018）**，打20只提鲁 `100123`，回报 | 每轮独立接、打、交 |
| 9 | 奇库接 **为了成为骑士的最后的训练（20019）**，打5只提古尔 `100124`，回报 | 旧版最后一轮只要3只，当前线是5只 |
| 10 | 到10级后回南哈特。想看职业展示可接 **5条岔路（20020）**；再办理 **选择的道路（20100）** | 选择“不看”会退出展示对话。只要20000、20001已经完成，就能接20100，无需先完成展示 |
| 11 | 找下表一位团长，接并交对应“××之路”，确认选择 | 完成对话后，打开角色信息查看职业，变成所选职业才算一转成功 |

奇库在修炼森林 `130010000`；提姆、提鲁可在相邻的 `130010100` 区域寻找，专用区域分别为 `130010110、130010120`；提古尔在 `130010200`，找不到时再去专用区域 `130010210`。打怪时留意任务栏是否涨计数，名字相近的怪物未必是同一个任务目标。

| 想玩的职业 | 找谁 | 一转任务 | 转职后职业ID／武器 |
| --- | --- | --- | --- |
| 魂骑士 | 米哈尔 | 魂骑士之路 20101 | 1100／剑 |
| 炎术士 | 奥兹 | 炎术士之路 20102 | 1200／法杖 |
| 风灵使者 | 伊莉娜 | 风灵使者之路 20103 | 1300／弓 |
| 夜行者 | 伊卡尔特 | 夜行者之路 20104 | 1400／拳套、飞镖 |
| 奇袭者 | 胡克 | 奇袭者之路 20105 | 1500／拳甲 |

一转需要达到10级、仍为贵族，并已完成20100。五个职业只能选一个，先想好再确认。转职时会重置基础能力值，并发放初始武器和初级勋章；风灵使者、夜行者另有箭矢或飞镖，记得给背包留空位。转职后重新分配AP，可参考[主副属性建议](cygnus-skills.md#能力值ap)。

做完训练还没到10级的话，就留在修炼森林打怪补足等级，再回南哈特。不同经验倍率、已有任务进度会影响升级速度；旧角色也可能已经领过部分奖励。

## 旧角色的另一套路线

只有当前任务确实属于旧线时使用。此线从女皇开始，不经过奇姆四兄弟的打箱教学：

| 顺序 | 任务／目标 |
| --- | --- |
| 1 | 希纳斯：女皇的会面20000 → 南哈特：谋士南哈特20001 → 奇库：修炼教官奇库20002 |
| 2 | 奇库的第一次修炼20003：提诺 `100120` **5只** |
| 3 | 奇库的第二次修炼20004：提布 `100121` **10只** |
| 4 | 奇库的第三次修炼20005：提姆 `100122` **15只** |
| 5 | 奇库的第四次修炼20006：提鲁 `100123` **20只** |
| 6 | 奇库的最后一次修炼20007：提古尔 `100124` **3只** |
| 7 | 骑士之路20008：完成奇库对话；10级后找南哈特办20100，再选一位团长完成一转 |

旧线有专门的任务标记和接取日期限制，新建角色按奇姆路线走即可。新版20013会自动完成旧线前三项，不用再回头补做。

## 一转后：实地适应训练与派遣任务

想继续骑士团剧情，可接南哈特的 **可以这样出去吗？（20700）**，再找奇库依次做20701～20703：**训练用绿水灵、训练用花蘑菇、训练用猪猪各30只**。这三项限 **10～15级**接取，想体验就趁早做。去第一演武场打对应的训练怪，普通同名怪物不计数。这段训练不影响二转。

前往金银岛可到圣地码头 `130000210` 找奇里鲁 `1100003`；返回圣地可到金银岛码头 `101000400` 找 `1100007`。每程1000金币，先留足往返旅费，和船夫确认目的地后再乘坐。

后续派遣线从13级开始，**不必清完才转职**。各段完成后带报告回圣地南哈特，再按等级接下一段。有几处任务说明写的数量与完成要求不同，下表已特别标出。

| 等级与任务段 | 任务做法 |
| --- | --- |
| 13～14级，射手村20704～20708 | 找洛卡：50只玩世不恭的花蘑菇 `9300274`＋花蘑菇玩偶1个；调查东部草丛 `100020000` 可点击黑影；之后打猪猪100只、漂漂猪50只＋猪猪玩偶1个。带报告与证物回南哈特 |
| 16～17级，废都20709～20714 | 找马迪尔斯：去地铁点击垃圾桶取蓝水灵玩偶 `4032136`；之后打100只蓝水灵、捡30个另一种蓝水灵玩偶 `4032137`。接“统统都打开！”后找权达开；资源另有20713，可交10把陈旧的钥匙 `4032139` 换真人偶。拿到 `4032138` 后回马迪尔斯，再带报告回南哈特。两个同名蓝水灵玩偶不能混交 |
| 18～19级，魔法密林20715～20719 | 找赫尔莎：到 `101010103` 取清澈的树液1份，交艾温；再到 `101010000` 采植物的果实10个，交赫尔莎；接“汉斯很可疑！”后调查汉斯住处，按入口进入隐藏图书馆，点击屋角触发剧情，任务完成后继续下一步。这里会突然出现蓝蘑菇，提前备好药水 |
| 25～26级，勇士部落20720～20724 | 先回南哈特取探测相关道具，再找布吉：木面怪人200只＋证物1个，石面怪人200只＋证物1个，最后带报告回南哈特。**20723叙述写20只，交付条件是200只**，看任务计数，不以叙述当作完成 |
| 28级，林中之城20725～20729 | 接总任务后分别找记忆者、萨比特拉玛、克利斯拉玛：指定僵尸蘑菇 `9101001` 250只、火独眼兽200只、刺蘑菇盖100个；再找奇怪的石像，完成四项情报后回南哈特。**僵尸蘑菇叙述引用2230101，实际计数要求9101001**，若不涨计数先核对模板，别持续打错目标 |
| 28级，抓住人偶师！20730 | 先接任务，再到火独眼兽洞穴的人偶师根据地入口，暗号为 **弗朗西斯是天才傀儡师！**（含全角叹号）。击败指定人偶师 `9300285` 1次，再回南哈特。已击杀、未接任务或入口场景不符时，不能只靠正确暗号进入 |

调查黑影后，20706会直接完成；点击图书馆屋角后，20718也会直接完成，并召出怪物。看到任务已经完成，就继续下一项，不用反复回去交同一项任务。

## 任务卡住了怎么办

接不到下一项任务时，先打开任务栏看看上一项是否已经完成，再检查等级和职业。20013会自动完成几项前置，找不到对应的可接任务时，也到“已完成”里翻一翻。

打怪不涨计数时，先确认自己已经接了任务，再看看打的是不是指定怪物。教学提诺和普通提诺、两种僵尸蘑菇尤其容易认错。需要材料的任务还得捡起掉落物，只有击杀数量满了仍然交不了。

数量和说明对不上时，留意任务栏的计数：石面怪人这项实际要求200只，林中之城的僵尸蘑菇则要打指定种类。两个同名蓝水灵玩偶的用途也不同，别把地铁垃圾桶里找到的那一个当成后续要收集的30个。

已经10级却转不了职时，先确认“选择的道路”已完成，并给装备栏留出空位。默认的新手设置会自动分配AP；如果所在服务器关闭了这一设置，当前五份一转脚本都会额外检查DEX是否达到25。遇到属性提示时，按提示检查自己的能力值。

- [骑士团出生创建器][creator]与[出生地图脚本][birth]：出生图130030000、新教学标记。
- [教学脚本目录][scripts]：20010～20013、20016、20017、20020、20100及20101～20105；20013自动完成旧任务，20020的退出分支，需和资源条件合读。
- [贵族一转脚本][first]及[一转属性检查][stats]：职业、初始物资、基础属性重置；不将脚本中未执行的提示当成实测保证。

- 派遣调查：[黑影][shadow]、[垃圾桶][trash]、[树液][sap]、[图书馆入口][libraryin]、[屋角剧情][library]、[人偶师暗号][password]。怪物、NPC与任务道具名称见[中文字符串目录][strings]。
