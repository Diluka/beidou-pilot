# 骑士团新手任务攻略

适用范围：北斗 V17 的骑士团贵族（职业1000），从圣地出生到10级一转，并附一转后的入门训练与13～28级派遣线。2026-11-11 按本地资源和固定公开源码整理，**本篇尚未实际创建骑士团角色走通**；路线、奖励及异常分支均属静态核验。各职业加点见[骑士团终态加点](cygnus-skills.md)。

## 先辨认自己的任务线

当前源码的新骑士团出生在 `130030000`，进入地图时标记新版教学线。见到**奇姆**时，按下节走；旧角色若已经接到“女皇的会面”或“奇库的第一次修炼”，跳到[旧版路线](#旧角色的另一套路线)。两套线由任务标记和互斥前置区分，不能把相似任务的击杀数量混用，也不必两套都做。

这里的“贵族”是骑士团新手职业，**不是冒险家职业0**。冒险家的[青苹果乐园路线](newbie.md)不能直接照搬：入口脚本只有职业0能传入乐园，职业1000进入其他分支；若当前角色的灯泡实际提供“来自北斗开发者的问候”，脚本有发10万金币后完成的分支，但本篇不保证该任务对骑士团一定可接，更不将16万乐园收益算入本路线。

## 当前出生路线：奇姆到一转

先接任务，再打怪、捡材料、交任务；每交完一项再找下一位。出生教学区主要沿箭头**向左**推进，之后按任务指引到圣地中心、修炼森林。

| 顺序 | 任务与做法 | 结果核对 |
| --- | --- | --- |
| 1 | 找奇姆接 **欢迎来到圣地！（20010）**，向左找奇赞交付 | 任务完成；脚本通常发贵族红、蓝药水各5瓶，消耗栏留空位 |
| 2 | 奇赞接 **告诉你狩猎的方法（20011）**，打1只教程解说员提诺，再回报 | 目标模板为 `9300328`；外形相同的普通提诺 `100120` 不替代此任务计数。脚本奖励贵族帽、贵族服 |
| 3 | 找奇努接 **你知道技能相关的事情吗？（20012）**，按提示学习、使用贵族攻击技能，打3只提布，并捡1个任务材料 `4000483` | 同时满足击杀与材料，交任务收走材料；不要只打不捡 |
| 4 | 找奇雅接 **这里有装着道具的箱子（20013）**，用**普通攻击**打箱，捡石材 `4032267` 和徽章 `4032268` 各1个 | 交付后得到椅子 `3010060`；这不是打怪任务，技能攻击不能代替敲箱 |
| 5 | 找奇莎接 **女王殿下正在等候你呢。（20014）**，回答教学题，取得初心者证书 `4032269`，带给女皇希纳斯 | 题目答案依次为 **Q、I、3点、一般攻击**；证书交付后消耗 |
| 6 | 查看已完成任务；若“向年轻女王行礼（20015）”仍可接，则向希纳斯行礼；随后找南哈特做 **你了解黑暗魔法师吗？（20016）** | 当前 `20013` 脚本会自动完成 `20000、20001、20002、20015`；因此看不到20015不一定是漏做，不要强求重接 |
| 7 | 去修炼森林找奇库，接 **为了成为骑士的第一次训练（20017）**，打15只提姆 `100122`，回报 | 不沿用旧版第一次修炼的“提诺5只” |
| 8 | 奇库接 **为了成为骑士的第二次训练（20018）**，打20只提鲁 `100123`，回报 | 每轮独立接、打、交 |
| 9 | 奇库接 **为了成为骑士的最后的训练（20019）**，打5只提古尔 `100124`，回报 | 旧版最后一轮只要3只，当前线是5只 |
| 10 | 到10级后回南哈特。想看职业展示可接 **5条岔路（20020）**；再办理 **选择的道路（20100）** | 展示不是转职。脚本的“不看”选项会退出对话，不保证完成20020；20100资源前置是20000、20001完成，不要求20020完成 |
| 11 | 找下表一位团长，接并交对应“××之路”，确认选择 | 核对职业ID已从1000变成目标职业；不要只看接到了任务 |

奇库在修炼森林 `130010000`；提姆、提鲁可在相邻的 `130010100` 区域寻找，专用区域分别为 `130010110、130010120`；提古尔在 `130010200`，找不到时再去专用区域 `130010210`。以实际地图与任务计数为准，不因为名字相近就换打其他模板。

| 想玩的职业 | 找谁 | 一转任务 | 转职后职业ID／武器 |
| --- | --- | --- | --- |
| 魂骑士 | 米哈尔 | 魂骑士之路 20101 | 1100／剑 |
| 炎术士 | 奥兹 | 炎术士之路 20102 | 1200／法杖 |
| 风灵使者 | 伊莉娜 | 风灵使者之路 20103 | 1300／弓 |
| 夜行者 | 伊卡尔特 | 夜行者之路 20104 | 1400／拳套、飞镖 |
| 奇袭者 | 胡克 | 奇袭者之路 20105 | 1500／拳甲 |

一转任务要求10级、仍为贵族，并已完成20100。五条路互斥，先决定职业再确认，不以试选方式体验。当前中文转职脚本会重置基础能力值、发初始武器和初级勋章，弓手、飞侠另有初始箭矢或飞镖；背包留出装备和对应道具空间。公开默认开启新手自动分配AP；若目标关闭该功能，这五份转职脚本都以 `jobType=3` 检查DEX至少25，和通常按各职业分别检查属性的攻略不同。遇到属性拦截先核对当前提示与配置。重置后核对未分配AP，再按[主副属性建议](cygnus-skills.md#能力值ap)分配，不把出生时的属性当作最终养成方案。

**奖励按实际到账核对。**本篇不承诺任务经验能精确把所有角色升到10级；倍率、已有任务记录会改变结果。不足10级时在已确认的训练区域补足，不通过混做两套互斥教学线凑经验。20010脚本的药水奖励还检查了另一项任务记录，因此表中写“通常”，不保证每个存量角色重复领到。

## 旧角色的另一套路线

只有当前任务确实属于旧线时使用。此线从女皇开始，不经过奇姆四兄弟的打箱教学：

| 顺序 | 任务／目标 |
| --- | --- |
| 1 | 希纳斯：女皇的会面20000 → 南哈特：谋士南哈特20001 → 奇库：修炼教官奇库20002 |
| 2 | 奇库的第一次修炼20003：提诺 `100120` **5只** |
| 3 | 奇库的第二次修炼20004：提布 `100121` **10只** |
| 4 | 奇库的第三次修炼20005：提姆 `100122` **15只** |
| 5 | 奇库的第四次修炼20006：提鲁 `100123` **20只** |
| 6 | 奇库的最后一次修炼20007：提古尔 `100124` **3只** |
| 7 | 骑士之路20008：完成奇库对话；10级后找南哈特办20100，再选一位团长完成一转 |

资源还给20000设置了旧结束日期，并要求旧教学标记。因此这段只用于识别历史任务记录，**不保证当前新建角色能主动切入旧线**。新版20013自动完成旧线前三项，是脚本衔接行为，不等于开放两条完整路线同时领取。

## 一转后：实地适应训练与派遣任务

想继续骑士团剧情，可接南哈特的 **可以这样出去吗？（20700）**，再找奇库依次做20701～20703：**训练用绿水灵、训练用花蘑菇、训练用猪猪各30只**。三项的资源接取范围是 **10～15级**；想完整体验应及时做。进入第一演武场按任务生成对应训练怪，普通同名怪物不能替代。此段不是二转的前置链。

前往金银岛可到圣地码头 `130000210` 找奇里鲁 `1100003`；返回圣地可到金银岛码头 `101000400` 找 `1100007`。这两个船只脚本每程收1000金币，先留足往返旅费，确认船的目的地后再乘坐；本轮未实测航程。

后续派遣线从13级开始，是可继续体验的早期剧情，**不必清完才转职**。各段完成后带报告回圣地南哈特，再按等级接下一段。下表的数字取自 `Check` 交付条件；有几处任务叙述与计数不一致，已经单列。

| 等级与任务段 | 可执行目标与回报 |
| --- | --- |
| 13～14级，射手村20704～20708 | 找洛卡：50只玩世不恭的花蘑菇 `9300274`＋花蘑菇玩偶1个；调查东部草丛 `100020000` 可点击黑影；之后打猪猪100只、漂漂猪50只＋猪猪玩偶1个。带报告与证物回南哈特 |
| 16～17级，废都20709～20714 | 找马迪尔斯：去地铁点击垃圾桶取蓝水灵玩偶 `4032136`；之后打100只蓝水灵、捡30个另一种蓝水灵玩偶 `4032137`。接“统统都打开！”后找权达开；资源另有20713，可交10把陈旧的钥匙 `4032139` 换真人偶。拿到 `4032138` 后回马迪尔斯，再带报告回南哈特。两个同名蓝水灵玩偶不能混交 |
| 18～19级，魔法密林20715～20719 | 找赫尔莎：到 `101010103` 取清澈的树液1份，交艾温；再到 `101010000` 采植物的果实10个，交赫尔莎；接“汉斯很可疑！”后调查汉斯住处，按入口进入隐藏图书馆，点击屋角触发剧情，再核对完成记录。该脚本会召出蓝蘑菇，事先补药，不在危险场景停留分析 |
| 25～26级，勇士部落20720～20724 | 先回南哈特取探测相关道具，再找布吉：木面怪人200只＋证物1个，石面怪人200只＋证物1个，最后带报告回南哈特。**20723叙述写20只，交付条件是200只**，看任务计数，不以叙述当作完成 |
| 28级，林中之城20725～20729 | 接总任务后分别找记忆者、萨比特拉玛、克利斯拉玛：指定僵尸蘑菇 `9101001` 250只、火独眼兽200只、刺蘑菇盖100个；再找奇怪的石像，完成四项情报后回南哈特。**僵尸蘑菇叙述引用2230101，实际计数要求9101001**，若不涨计数先核对模板，别持续打错目标 |
| 28级，抓住人偶师！20730 | 先接任务，再到火独眼兽洞穴的人偶师根据地入口，中文脚本暗号为 **弗朗西斯是天才傀儡师！**（含全角叹号）。击败指定人偶师 `9300285` 1次，再回南哈特。已击杀、未接任务或入口场景不符时，不能只靠正确暗号进入 |

上表派遣线也尚未实测；调查点击、掉落、入口与任务脚本可能直接完成任务，不能要求所有段落都表现为“计数满后再交”。黑影脚本会直接完成20706；图书馆屋角脚本会直接完成20718并生成怪物。每次交互后重新检查任务状态，已完成就继续下一项。

## 停止条件与现场核对

- 接不到任务：先查职业、等级、前置和已完成记录；尤其不要把20013自动完成的任务误判为丢失。保留任务名、ID与当前状态，再复核资源或服务器版本。
- 不涨计数或无法交付：确认任务已接、怪物模板正确、材料已捡、背包有空间。20011、20723和20726的叙述尤其容易误导。
- 转职或剧情有异常：停止重复确认，不为补进度重置角色或修改存档。本文没有授权操作任何账号或服务器。
- 现场验证时使用已授权专用角色与隔离目标，分别记录出生地图、任务接交、实际掉落、奖励到账及最终职业。新手路线尚未实测，不能用登录成功代表整条任务已走通。

## 来源与验证状态

公开来源固定在 [BeiDou-Server `00422c2`][source]；本地北斗 V17 `Quest.nx` 中本文教学、转职、实地训练和100／110级技能训练的名称、条件、奖励，与对应基础及中文覆盖资源核对一致。地图位置、脚本分支及13～28级派遣说明按下列公开资料核实；没有核对常驻服当前数据库配置或做实际试玩。

- [任务名称与叙述][questinfo]、[条件与计数][check]、[奖励与技能授予][act]、[问答与提示][say]：基础资源；中文覆盖在[中文任务目录][questzh]，不能只读其中一套。
- [骑士团出生创建器][creator]与[出生地图脚本][birth]：出生图130030000、新教学标记。
- [教学脚本目录][scripts]：20010～20013、20016、20017、20020、20100及20101～20105；20013自动完成旧任务，20020的退出分支，需和资源条件合读。
- [贵族一转脚本][first]及[一转属性检查][stats]：职业、初始物资、基础属性重置；不将脚本中未执行的提示当成实测保证。
- [圣地出发船只][shipout]与[金银岛返程船只][shipback]：目的地与船费；NPC位置见基础 `Map.wz/Map/Map1/130000210、101000400.img.xml`。
- [青苹果入口][apple]：传送判断为职业0，未将冒险家支线直接套用骑士团。
- 派遣调查：[黑影][shadow]、[垃圾桶][trash]、[树液][sap]、[图书馆入口][libraryin]、[屋角剧情][library]、[人偶师暗号][password]。怪物、NPC与任务道具名称见[中文字符串目录][strings]。

本文交付的是可复核的研究攻略；**内容完成与游戏验证通过分开记录**。下一次有对应玩家试走时，优先核对20011目标、20013自动完成记录、20100可接性和转职后的物资，再补派遣线的计数差异。
