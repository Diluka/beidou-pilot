# 四转技能书获取与解锁指引

供北斗 V17 冒险家使用。各职业要找哪些书、最后加多少点，见[四转加点攻略](adventurer-fourth-job.md)的职业终态表；本篇集中说明书怎么用、去哪里查当前掉落，以及没有普通能手册的技能该找哪条任务。这里只提供可执行的查询入口和解锁线索，不把旧版掉落表当成当前服保证。

## 先分清你缺的是什么

| 当前情况 | 下一步 |
| --- | --- |
| 技能没有出现，或技能0级且上限0 | 查本篇“技能没有出现或上限为0”，找转职授予、习得书或技能任务 |
| 技能已有0/10 | 已有10级可学上限，不必再用同技能的10级习得书，直接花SP |
| 当前上限10，要继续到20 | 技能实际至少5级后，用对应20级能手册 |
| 当前上限20，要继续到30 | 技能实际至少15级后，用对应30级能手册；不用先加到20 |
| 灵魂治愈、灵魂祝福或强化圣龙卡上限 | 做对应提高上限任务，普通20／30能手册只到20 |

本篇所涉228习得书成功率100%；229的20级册为70%、30级册为50%。成功是**提高能手上限**，不会直接送实际技能等级；符合使用条件而失败时也会消耗一本。书可能通用于同类职业的同名技能，按四转表的物品ID核对，不只看简称。

例如：轻舞飞扬已有5/10，成功用2290010后是5/20；再花10 SP到15/20，成功用2290011后是15/30，然后才能继续加。冒险岛勇士的共用书是2280003（习10）、2290096（20）、2290125（30）；勇士的意志用2280002解锁至5，无20／30册。船长5221010也映射2280002，但本版本名称与增益槽异常，不能据此当作勇士意志，见[船长规划](adventurer-fourth-job.md#船长522)。

## 去哪里查当前掉落

### 脚本中心查询

1. 打开游戏内脚本中心（NPC9900001），选“爆率一览”。
2. 选“系统物品爆率查询”→“职业技能书”。
3. 按四转终态表的物品ID找对应书，查看怪物名称、ID和掉率提示，再按该怪物的分布选择刷书地图。

该分类覆盖2280000～2299999。列表每页50项，查询最多取200种物品，单本最多显示30条掉落记录；**列表未收录表示来源待查**，查不到时再用阿得拉、任务线索或当前服其他公开说明交叉核对。脚本中心的“学习技能”是独立功能，四转技能书商店按对应入口查找。

### 找阿得拉

阿得拉（NPC9209000，名称下可能显示“中介商人”）的本版本脚本提供职业技能书／能手册说明。可在射手村、明珠港、天空之城、神木村、阿里安特、新叶城、上海等城镇找他，地图分别为100000000、104000000、200000000、240000000、260000000、600000000、701000100。

四转后与他对话，选当前可用的技能书或能手册，再查看掉落怪物、任务或探索来源提示。能手册列表会按当前技能等级、已有上限和职业过滤：还没达到5级或15级，可能看不到下一本；列表为空时按当前等级与已学记录继续核对。怪物名单和来源提示提供线索，具体流程按提示再核对目标地图或任务记录。

## 技能没有出现或上限为0

先查角色当前实际技能等级与能手上限。正常转职只登记部分基础技能；快速转职脚本虽然尝试补技能，但有错ID和遗漏，不能认定“四转即全技能”。

其他技能先看四转表：标“习10／习5”的按物品ID查询习得书；标任务的查下面任务入口。正常四转还会给冒险岛勇士习得书2280003，留出消耗栏空位。

完成正常四转考验的角色，可回对应教官查看“教我我的职业技能”：战士哈尔模尼亚（2081100）、法师格里特（2081200）、弓手列高罗（2081300）、飞侠哈林（2081400）、海盗邪魔尔（2081500）。这只补各系脚本列出的部分技能到0/10，全技能教学与25／30级上限走各自任务。

该对话仍检查正常四转任务完成状态（各系分别6904、6914、6924、6934、6944）。只走快速转职的角色未必满足，因此看不到教学选项时先核对任务记录，不要反复点击；改查对应习得书或任务线。法师教学脚本还存在重复技能ID，不能承诺它能补齐所有缺失技能。

## 常见卡点

- **书吃了，技能怎么还是原级？** 看能手上限是否提高，再花SP；书不会自动加点。
- **有30级书却不能用？** 先确认同一技能已实际15级、对应20级上限已开，且职业与物品ID相符。
- **任务做完仍不能超过10？** 看它授予的是初始10还是后续上限；黑骑士灵魂技能、主教强化圣龙要继续对应提高上限的任务。
- **查询没有结果？** 分类条数、NPC可用条件和怪物名单均有限制，再查另一入口及任务记录；不能据此断言技能书已绝版。
- **书没到手，升级点怎么办？** 按四转职业章的“缺书顺序”补已解锁核心，或暂留SP；不要把其他武器或低优先级技能提前点满。
