# 冒险家一转职业任务攻略

本文覆盖冒险家五系可在30级之前接取的职业任务，并追踪依靠前置而没有单独等级下限的后续。资源存在不代表必须在30级前完成；资料为北斗 V17 固定版本静态整理，尚未逐职业试玩。

## 其他低级职业任务线索

- **新手冒险家（29900）**：资源列为8级起、冒险家一转五系，提示NPC为达利尔 `9000040`；脚本显示启动后可领取勋章 `1142107`，背包须有空位。资源条件按服务端代码要求未持有该勋章；实际触发和领取尚未试玩，找不到任务时以现场提示为准。
- 弓箭手 **弓箭手之路（6700）**、海盗 **升级活动（9950）**及阿莫利亚各职业任务 `8863～8866／28102` 也有30级前的等级字段，但分别涉及历史活动或婚礼任务前置。阿莫利亚前置 `8862` 资源的最低等级为10020，婚礼是否会以其他方式完成该前置尚未核实；这些暂作线索，不当作现服可走通的攻略。服务端对部分早期结束日期有特殊处理，不能只凭历史日期判断活动是否关闭。

## 五系基础修炼

冒险家战士、魔法师、弓箭手、飞侠、海盗分别找自己的金银岛导师。对应骑士团职业也在任务职业条件内：魂骑士、炎术士、风灵使者、夜行者、奇袭者分别对应下表五行；战神也可做战士这一行。每轮先接任务，完成击杀后回表中导师交付，再接下一轮。任务的接取等级上限为 **40级**；四轮分别登记任务编号，不是一次累计击杀数量。

海盗最后一轮的指定绿蘑菇与普通同名怪物可能不是同一个目标，先接任务并观察计数。任务资源的基础经验：法师四轮依次为290、323、345、470；其他四系依次为590、610、645、840，实际经验受服务器倍率影响。资源还列有药水和回城卷奖励；海盗奖励存在职业位掩码，奇袭者是否能拿到相同物品需以实际结果为准。

## 首领之后：五份线索与地狱大公

完成自己职业的首领任务并向导师交付后，检查背包是否获得神秘徽章 `4032496`。五系首领任务的资源奖励均为基础经验5,000、对应帽子及这枚徽章；法师28198还会收走牛魔王入场徽章 `4032495`。神秘徽章 `4032496` 是下面五项线索任务共同的接取条件：**五系都能接五项，不是只做自己职业对应的那一项**。资源未给五项单独设置最低等级；仍需满足徽章等条件。

| 任务 | 接取、交付NPC | 到任务提示的地点附近打怪取得 |
| --- | --- | --- |
| 28257 谁解开了印第安老斑鸠的封印？ | 勇士部落武术教练 | `102020300` 附近，黑斧木妖 `2130100`，纸张(1) `4001367` |
| 28258 谁解开了沃勒福的封印？ | 废弃都市达克鲁 | `103030200` 附近，刺蘑菇 `2110200`，纸张(2) `4001368` |
| 28259 谁解开了黑暗独角兽的封印？ | 射手村赫丽娜 | `104040002` 附近，绿蘑菇 `1110100`，纸张(3) `4001369` |
| 28260 谁解开了雪之猫女的封印？ | 诺特勒斯凯琳 `1090000` | `100030000` 附近，漂漂猪 `1210101`，纸张(4) `4001370` |
| 28261 谁解开了牛魔王的封印？ | 魔法密林汉斯 | `101010102` 附近，黑木妖 `1110101`，纸张(5) `4001371` |

例如法师击败牛魔王并交28198后，不能把28261当成终点：持神秘徽章到五位导师分别接取、完成28257～28261，并保留五张纸。海盗线的任务叙述提到NPC `1072008`，条件资源中的接交NPC是凯琳 `1090000`；以现场提示核对。表中怪物来自固定版本的掉落迁移数据，地图来自任务文本；当前服务器的掉落配置与实际刷新尚未实测。五项每项基础奖励2,000经验，交付线索任务不消耗纸张。

五项全完成且持有五张纸后，找林中之城**记忆者** `1061011` 接交 **揭示的身份（28262）**；交付会消耗五张纸。25级起完成三项记忆者培训（28263～28265）：分别击杀刺蘑菇 `2110200`、僵尸蘑菇 `2230101`、火独眼兽 `2230100` 各50只，逐项回记忆者交付。三项完成后接交 **地狱大公的秘密（28266）**。

继续在记忆者处接 **如何躲避恶臭（28282）**，收集野猪皮 `4001372`、邪恶之眼的眼球 `4000008`、道符 `4001373` 各30个并交付；然后接 **为了金银岛的和平…（28283）**，先装备28282奖励的防毒面具 `1003036`，到 `105050400` 与入口NPC `9201133` 对话进入；入口脚本要求28283进行中且装备面具。击败地狱大公 `9400633` 1只后回记忆者交付。28282、28283均为25级起，实际入场和任务结果尚未试玩。
