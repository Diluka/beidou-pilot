# 彩虹岛新手任务攻略

北斗有两套可以先后体验的新手流程：出生后直接开始的是原版彩虹岛任务，头顶灯泡里的“来自北斗开发者的问候”则通往额外的青苹果乐园。想两套都体验，建议先做灯泡支线，再回头继续原版任务。

适用范围：冒险家新手。2026-11-11 按本地客户端资源、北斗源码及隔离服原版 GUI 试玩整理；逐项验证范围见文末。骑士团另见[圣地新手攻略](cygnus-newbie.md)，战神的出生流程不在本文范围内。

## 先走灯泡支线：青苹果乐园

尽量在 **10级及以下、尚未转职** 时进入。资源中这组任务的接取上限是10级，入口脚本还会检查是否为“新手”职业。已经开始原版流程也能进入，本轮实测从6级、彩虹岛中途进入成功。

| 顺序 | 找谁、做什么 | 注意事项 |
| --- | --- | --- |
| 1 | 双击角色头顶灯泡，选择 **[北斗冒险岛]来自北斗开发者的问候**，读完并同意前往青苹果乐园 | 到达后是“踏入旅途”，先找面前的昨日酣睡 |
| 2 | 向 **昨日酣睡** 交欢迎任务，领取 **10万金币**；再与她交谈出发 | 领钱和进入教学区是两次交互；只传送进去还没有领钱 |
| 3 | 找 **莎丽** 接“你好，我是莎丽”，参观职业展示后找 **罗杰** 交任务 | 这一段从入口向左走。可以跳上履带参观，左端传送点通往下一段 |
| 4 | 到玩具城布景找 **透德**，接“透德的打猎法”，击杀 **5只打鼓兔子** 后回来交任务 | 奖励 **1万金币**。先接再打，别只看见怪物就直接清掉 |
| 5 | 继续向右，到雪地布景找 **彼特**，接“彼特的打猎法”，击杀 **5只小白雪鬼** 后回来交任务 | 奖励 **5万金币** |
| 6 | 向右找到 **希娜**，接“旅途的终点，冒险的开始”，再和她对话交任务、确认送出 | 结束后返回原版流程的开头，不是自动送到明珠港 |

教学区里的兔子和雪鬼是教学用怪物，不必跑去真正的玩具城或冰峰雪域。两者资源均为1级、8点HP，普通攻击即可；仍要注意接触伤害和自己的HP。

找不到怪物时，留意传送带上方的平台。站在最底层往往够不到怪物；可以先跳上传送带，再跳上怪物所在的台面，或利用旁边的台阶。传送带会带着角色移动，交完任务后再继续走，避免直接被送过头。

这条路线三笔任务奖励合计 **16万金币**，本轮已全部实收。结束时先回到开场动画，随后到原版的“小蘑菇”地图，可以重新找希娜继续教学；之前已经接取、完成的原版任务不会因此重置。

完成一项后，核对任务已进入“已完成”和金币变化，再去下一站。莎丽、罗杰、希娜等名字在两套流程中会重复出现，按当前任务全名区分。

## 回来后，继续原版彩虹岛任务

原版路线以 NPC 头顶任务提示和任务栏为准；不要求清完所有支线才能离岛。下面是主要的新手教学与修炼顺序，任务要求来自客户端资源。

| 路段 | 任务与做法 |
| --- | --- |
| 出生区域 | **希娜和莎丽**：与希娜说话，再找右边晒衣服的莎丽，然后从右侧传送点前进 |
| 罗杰处 | **罗杰和苹果**：按提示打开背包，吃掉他给的任务苹果，再回来交任务；普通苹果与任务苹果不是同一种道具 |
| 妮娜处 | **妮娜弟弟珊 → 珊想吃的东西 → 好吃的蘑菇棒棒糖**：进民宅问弟弟想吃什么，回报妮娜，再把棒棒糖送进去 |
| 蘑菇村东入口 | **透德的打猎方法**：击杀1只小石球，捡起1个任务石片，交给彼特；它和灯泡支线的“打猎法”是两项任务 |
| 危险的树林 | **学者罗宾**：完成教学问答；向叁接 **帮助打猎蜗牛**，击杀10只蜗牛后找玛丽亚报告 |
| 彩虹村 | 从玛丽亚接 **玛丽亚的信**，送给长老路卡斯；再接 **长老的介绍**，前往东边找麦加修炼 |
| 麦加修炼 | 依次完成：**木妖5只＋树枝3个 → 红蜗牛5只 → 绿水灵3只＋绿液球1个 → 特殊花蘑菇2只**。每轮交完再接下一轮 |
| 修炼收尾 | 四轮完成后回路卡斯交“长老的介绍”，资源奖励包含推荐信；还想继续体验，可找白瑞德做测试，再接比格斯的金银岛故事 |

原版任务也有等级、职业和前置限制，很多任务要求10级及以下的新手；想完整体验就边走边交，不要先把等级练高或转职。任务要求收集材料时，打完还要捡起掉落物；提前击杀的怪物不应当作接取后的任务进度。

麦加最后一轮的“花蘑菇”与白瑞德测试要求的普通花蘑菇使用不同怪物模板，外形相似也不能互相顶数；以任务进度实际增加为准。

## 想离开彩虹岛，怎样选

**出现“跳过教程，直接前往明珠港”的提示时**，愿意跳过就确认；想继续原版流程就拒绝。不过，这个提示并非所有新号都有：当前源码在出生区检查 **同账号是否已有至少30级的角色**，满足才打开这段对话。灯泡支线结束本身不等于取得该资格。本轮测试账号未验证这条快捷出口，不能保证每个新号回来都会看到它。

**没有快捷提示时**，可以继续原版任务，也可以按正常地图路线走到南港找桑克斯乘船：彩虹村 → 冒险家修炼场入口 → 选择之岔路 → 南港。当前资源对应的南港是 `2000000`，不要与旧版同名地图 `60000` 混淆。

正常船只脚本的条件是：没有推荐信时 **至少7级，并支付150金币**；持有“长老的介绍”奖励的路卡斯推荐信时可免费乘船，出发时会收走信。无需为了省150金币而强行清完整条修炼线。

离岛前先确认还想做的任务和奖励已经处理完，留好药品与后续旅费。到明珠港后再按想玩的职业继续，不必为了清新手任务拖延自己的转职计划。
