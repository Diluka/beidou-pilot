# 商店位置与种类

本表按地图寻找普通 NPC 商店；坐标为地图静态 life 节点的游戏坐标 `(x, y)`，不是小地图像素。先用世界地图规划到场景，再寻找 NPC；同名场景以地图 ID 区分。商品种类依据迁移中的物品 ID 大类归纳，仅表示该类有商品，不保证有特定物品、库存或售价。

查找最近商店时，先从当前地图及相邻区域筛选所需商品大类，使用 [世界地图](world-map.md) 和 `tools/world_route.py <当前地图ID> <商店地图ID>` 比较候选门户路线；同一地图再结合 NPC 坐标与现场地形判断。门户数量只是距离的近似，不能保证实际耗时最短；路线不通时不要断定商店不可达。

仅静态交叉结果，尚未游戏实测。表格只是用迁移的 `shops.npcid` 与地图 NPC ID 相连，同一 NPC 对应多个 shop ID 不意味着全部可从其对话打开；场景不可达、任务条件、脚本覆盖、服务器实际数据库变动与商品售卖条件均可能使结果不同。无头客户端不支持普通 NPC 商店交易；GUI 的实际交易仍须现场核对。世界地图线路工具只覆盖普通门户，跨区船运等需另行确认。
