# 快捷交通与普通跑图

使用 `python3 /game/.agents/skills/beidou-game-guide/tools/world_route.py 起点地图号 终点地图号` 比较普通门户候选与已收录的出租车、飞艇候选。起终点是地图号或唯一地图名，不是场景内坐标。输出的 `planning_legs` 是简化规划段数；一段飞艇包含候船、上船、航行、下船，不能当作实际换图次数或预计用时。不存在免费门户候选，不等于不能步行到达；付费候选也不保证能到达 NPC 或满足使用条件。

## 金银岛普通出租车

客户端资料中，射手村、魔法密林、勇士部落、废弃都市、明珠港及诺特勒斯号码头均有出租车 NPC。固定版本脚本中的普通票价按目的地通常为 800 或 1,000 金币；`jobId == 0` 时按十分之一计算。路线工具逐段输出 NPC 编号、坐标和基础票价。实际运行服务器可能使用其他脚本、价格或条件。

- 废弃都市 `103000000` → 勇士部落 `102000000`：NPC `1052016`，客户端资源坐标 `(1796,152)`；基础票价 1,000。2026-11-13 在常驻服旧版 GUI 客户端实际验证：NPC 菜单显示 1,000，确认后地图变为 `102000000`，金币减少 1,000。落图后位于西侧 `(85,1690)` 附近；不能据此断定场景内能通往其他位置。
- 明珠港 NPC `1002007` 的脚本在持有 `4032313` 时继续对话会自动消券并传送射手村，不进入普通目的地菜单。魔法密林 NPC `1032000` 前往射手村时有 `4032288` 可免费消券。券、职业与脚本版本影响实际结果。

## 其他路线

已收录固定版本脚本中部分区域出租车，例如冰峰雪域、玩具城、神木村的定点路线；NPC 及基础票价由工具输出。客户端资源未找到对应 NPC 的脚本分支不列为已知捷径。

魔法密林和天空之城之间存在购票及检票的飞艇候选，单程基础票价 5,000 金币；已持票时新增费用可能不同。购票、检票、登船与抵达分布在不同阶段，需航班开放，等待时间及检票点可达性未验证。工具把它作为条件候选，不保证用户一定能从售票点抵达检票点。
