# 快捷交通与普通跑图

本文是出租车、飞艇等付费交通的离线静态资料，记录费用、NPC 坐标与已知条件，不提供路线计算。跨图路线统一用客户端原生 `beidou-pilot world-map route <起点地图号> <终点地图号>` 查询（需要同目录已有运行中的客户端）；该模型只覆盖普通门户，不含出租车、飞艇等付费交通，付费交通需对照本文与现场 NPC 自行判断。起终点是地图号，不是场景内坐标。不存在免费门户候选，不等于不能步行到达；付费交通也不保证能到达 NPC 或满足使用条件。

## 金银岛普通出租车

客户端资料中，射手村、魔法密林、勇士部落、废弃都市、明珠港及诺特勒斯号码头均有出租车 NPC，六个城镇之间互相可选为目的地。固定版本脚本中的普通票价按目的地通常为 800 或 1,000 金币；`jobId == 0` 时按十分之一计算。实际运行服务器可能使用其他脚本、价格或条件。

| 城镇 | 地图号 | 出租车 NPC | 客户端资源坐标 |
|---|---|---|---|
| 射手村 | 100000000 | 1012000 | (149,267) |
| 魔法密林 | 101000000 | 1032000 | (117,-37) |
| 勇士部落 | 102000000 | 1022001 | (766,1864) |
| 废弃都市 | 103000000 | 1052016 | (1796,152) |
| 明珠港 | 104000000 | 1002007 | (2750,-232) |
| 诺特勒斯号码头 | 120000000 | 1092014 | (1364,-419) |

- 目的地为魔法密林 `101000000` 或诺特勒斯号码头 `120000000` 时基础票价 800，其余城镇 1,000。
- 废弃都市 `103000000` → 勇士部落 `102000000`：NPC `1052016`，客户端资源坐标 `(1796,152)`；基础票价 1,000。2026-11-13 在常驻服旧版 GUI 客户端实际验证：NPC 菜单显示 1,000，确认后地图变为 `102000000`，金币减少 1,000。落图后位于西侧 `(85,1690)` 附近；不能据此断定场景内能通往其他位置。
- 明珠港 NPC `1002007` 的脚本在持有 `4032313` 时继续对话会自动消券并传送射手村，不进入普通目的地菜单。魔法密林 NPC `1032000` 前往射手村时有 `4032288` 可免费消券。券、职业与脚本版本影响实际结果。
