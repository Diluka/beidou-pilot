# 冒险家二转加点规划

适用范围：北斗 V17 冒险家，覆盖12条二转分支，以继续三转、四转为目标。2026-11-11 核对客户端技能资源与固定公开源码；**配点是研究建议，尚未逐职业实测**。本篇给出二转终态，不展开逐级加点、三转终态或四转阶段规划。

阅读顺序：先确认职业与武器，再找对应终态表，最后检查“四转前置”和“三转前核对”。表中的数字是最终技能等级，不是本次要追加的点数。

## 职业群规则与预算

冒险家从战士、魔法师、弓箭手、飞侠、海盗五系出发，30级选择二转分支，70级三转，120级四转；魔法师一转从8级开始，其余四系从10级开始。二转选定分支后，后续沿该职业树成长，不把其他分支的技能当作可自由混点的技能池。

**能力值 AP 支持自动分配**；AP 与技能点 SP 分开，本篇只安排 SP。

以下以30级及时二转、升级每级3 SP为基准：二转奖励1点，31～70级共40次升级获得120点，合计 **121 SP**。70级拿到升级点后、进行三转前核对终态；不把三转奖励点计入本表。一转原有投入另算，表中明确写出的“一转补点”才从这121点中支付。延迟转职、额外赠点或不同服务器配置，应先按角色实际记录核对，不能直接认定点数相同。

本篇通解优先保证主武器、常用攻击、移动和辅助能力。终极攻击、备用武器及低优先技能存在取舍；这是一个可执行方案，不表示每种装备、练级地点下都唯一最优。已经加过点的角色先比较差额，勿照着表再追加同样数量。

## 战士

### 剑客 → 勇士 → 英雄

通解以**剑**为主武器；走斧路线时，将下表的精准剑、终极剑、快速剑分别与对应斧技能交换。

| 技能 | 终态等级 |
| --- | ---: |
| 精准剑 | 20 |
| 终极剑 | 30 |
| 快速剑 | 20 |
| 愤怒之火 | 20 |
| 伤害反击 | 30 |
| 精准斧 | 1 |
| 终极斧、快速斧 | 0 |
| **合计** | **121** |

主武器三项共70点，辅助两项共50点，最后1点留作备用武器入门；也可改补一转尚未满的技能，二转主体仍为120点。若尚未决定剑或斧，先确定长期武器，再投入对应的终极与快速，不同时把两套都点满。

### 准骑士 → 白骑士 → 圣骑士

通解同样以**剑**为主；钝器路线将剑系三项与对应钝器技能交换。

| 技能 | 终态等级 |
| --- | ---: |
| 精准剑 | 20 |
| 终极剑 | 30 |
| 快速剑 | 20 |

| 终极钝器、快速钝器 | 0 |
| **合计** | **121** |

最后1点可按剑客的同样规则补一转。后续三转属性技能分剑、钝器，保持武器路线一致；本篇没有把“剑、钝器都点满”作为通解。

### 枪战士 → 龙骑士 → 黑骑士

采用**枪、矛双修**，保留后续根据武器和攻击方式切换的空间。

| 技能 | 终态等级 |

这里明确放弃终极，将点数留给两类武器支持。神圣之火需要极限防御至少3级；终态11级已经满足。此方案的价值是保留双武器使用能力，不宣称终极技能无效或不触发。

若更重视后续减速控场，可将毒雾术从30改为11、缓速术从1改为20，总数仍为121；这是舍弃部分二转毒攻击的替代方案，不是四转硬性前置。

## 弓箭手

| --- | ---: |
| 精准弓 | 20 |

| 爆炸箭 | 30 |
| 强弓 | 20 |
| 终极弓 | 0 |

保留群攻、近身击退与弓系支持，不投资终极弓；将余点补一转。**精准弓最终必须20级**，不能沿用“19级就够”的省点方案后忘记补满，原因见四转前置。

### 弩弓手 → 游侠 → 箭神

| 技能 | 终态等级／投入点数 |
| --- | ---: |
| 精准弩 | 20 |
| 快速弩 | 20 |
| 无形箭 | 20 |
| 穿透箭 | 30 |
| 强弩 | 20 |
| 终极弩 | 0 |
| 一转补点 | 11点 |
| **合计** | **110＋11＝121点** |

同样保留群攻、近身击退与武器支持。二转**穿透箭（3201005）**与四转同名的**穿透箭（3221001）**是不同技能，二转点满不会代替四转技能习得。精准弩终态20级也是四转前置。

**两条弓手路线的一转补点方法：**按当前一转记录，优先补集中术至20，再补精准箭至12，仍有余点就补尚未满的一转技能，合计只追加11点；已满项目跳过。这里的11是支出预算，不是“一项技能终态11级”。不把余点保留为未分配来假定正常三转一定放行，也不借三转SP把二转主体强行补成全满。

两条路线均须先有对应精准5级才能学快速，对应快速5级才能学无形箭。终极为0是通解的预算选择，不据此断言北斗客户端的所有终极触发行为。

| --- | ---: |
| 强体术 | 10 |
| 精准拳 | 20 |
| 急速拳 | 20 |

**强体术应尽早点满10。**它影响后续升级获得的最大HP，终态相同不代表早加、晚加得到相同的成长；不能把它作为最后再补的普通余点项。源码按升级当时的技能等级加HP，本篇不承诺晚加会追补历史收益。

急速拳需精准拳5级，而且终态20涉及四转极速领域前置。橡木伪装只保留1级，将有限SP留给其余战斗与补给技能；不把桶伪装当作无敌或安全挂机保证。

## 为四转保留的二转要求

核对12个四转职业的技能资源 `req` 后，直接引用二转技能的要求如下；已包含在通解中。

| 四转职业／技能 | 二转要求 | 本篇安排 |
| --- | --- | --- |
| 神射手：神箭手（3120005） | 精准弓（3100000）20级 | 保留20级，不省最后1点 |
| 箭神：神弩手（3220004） | 精准弩（3200000）20级 | 保留20级，不省最后1点 |

本次扫描未发现其余四转职业的 `req` 直接引用二转技能；这只说明这类显式前置，不表示二转的增益、被动或武器支持到了四转就无用。主教召唤龙、弓手凤凰、船长导航等涉及**三转**技能的前置，留在三转及对应四转攻略核对，不从本篇推算。

## 技能书与三转前核对

**本篇列出的二转技能均无需技能书或能手册**，满足前置后用SP提升即可。对技能资源及228／229类书籍的技能映射交叉核对，未发现这些二转技能对应的习得书或上限书；无需为完成本篇终态去刷四转书。

四转的技能书获取另由独立攻略说明，不在本篇展开。本轮资料中尚无已发布、可读的技能书获取攻略入口；后续四转子任务须补正式入口，当前不把它标成已经衔接完成。

进行三转前，逐项核对：

1. 当前职业ID、武器路线与所用表格一致，别把枪战士的“精准枪”与火枪手的同名技能混用。
2. 121点预算按表结算；弓手包含追加到一转的11点，剑客／准骑士最后1点的去向也已记清。
3. 所有已学后续技能满足前置，四转将用到的精准弓、精准弩或急速拳已达20。
4. 拳手强体术的实际加点时机已记录；已经晚加时，不用表格终态掩盖历史HP差异。
5. 若客户端显示的技能上限、名称或可投入点数与本文不符，先停止新增投入，保留技能ID、当前等级和剩余SP供复核。不要用高转SP或其他分支技能来消除差额。
