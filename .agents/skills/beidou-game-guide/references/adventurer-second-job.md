# 冒险家二转加点规划

这篇攻略列出北斗 V17 冒险家12条二转分支的最终加点，适合准备继续三转、四转的角色。按自己的职业和武器找到对应表格即可，三转后的分配见[三转攻略](adventurer-third-job.md)。配点按技能资料整理，尚未逐职业试玩，来源见文末。

表中的数字是最终技能等级。已经加过点的角色只需补差额，例如技能已有10级、表中写20级，就再加10点。

## 职业与技能点

冒险家从战士、魔法师、弓箭手、飞侠、海盗五系出发，30级选择二转分支，70级三转，120级四转；魔法师一转从8级开始，其余四系从10级开始。二转选定分支后，三转、四转会沿着这条路线成长。

**能力值 AP 支持自动分配**；手动加点按下表区分主、副属性。

| 职业大类 | 主属性 | 副属性 |
| --- | --- | --- |
| 战士 | 力量 STR | 敏捷 DEX |
| 魔法师 | 智力 INT | 幸运 LUK |
| 弓箭手（弓／弩） | 敏捷 DEX | 力量 STR |
| 飞侠（标／刀） | 幸运 LUK | 敏捷 DEX |
| 海盗拳手 | 力量 STR | 敏捷 DEX |
| 海盗火枪手 | 敏捷 DEX | 力量 STR |

**分配规则：副属性补到目标装备需求（计入装备加成），其余全加主属性，不固定按4∶1分配。**战士还需保证命中；使用力量型短刀时另补装备要求的STR。AP与下文技能点SP分开计算。

以下以30级及时二转、升级每级3 SP为基准：二转奖励1点，31～70级共40次升级获得120点，合计 **121 SP**。这些表对应70级升级后、三转前的技能等级，三转奖励点另算。一转原有投入另算，表中明确写出的“一转补点”才从这121点中支付。如果延迟过转职、拿过额外赠点，或服务器设置不同，先算清自己已花的点数和剩余SP，再按实际可用点数补。

推荐方案优先加满主武器支持、常用攻击、移动和辅助技能，终极攻击、备用武器等项目按点数取舍。文中也列出偏重控制、回复或其他打法的换点办法，可以按自己的练级习惯选择。

## 战士

### 剑客 → 勇士 → 英雄

推荐方案以**剑**为主武器；走斧路线时，将下表的精准剑、终极剑、快速剑分别与对应斧技能交换。

| 技能 | 终态等级 |
| --- | ---: |
| 精准剑 | 20 |
| 终极剑 | 30 |
| 快速剑 | 20 |
| 愤怒之火 | 20 |
| 伤害反击 | 30 |
| 精准斧 | 1 |
| 终极斧、快速斧 | 0 |
| **合计** | **121** |

主武器三项共70点，辅助两项共50点，最后1点留作备用武器入门；也可改补一转尚未满的技能，二转主体仍为120点。若尚未决定剑或斧，先确定长期武器，再投入对应的终极与快速，不同时把两套都点满。

### 准骑士 → 白骑士 → 圣骑士

推荐方案同样以**剑**为主；钝器路线将剑系三项与对应钝器技能交换。

| 技能 | 终态等级 |
| --- | ---: |
| 精准剑 | 20 |
| 终极剑 | 30 |
| 快速剑 | 20 |
| 压制术 | 20 |
| 伤害反击 | 30 |
| 精准钝器 | 1 |
| 终极钝器、快速钝器 | 0 |
| **合计** | **121** |

最后1点可按剑客的同样规则补一转。后续三转属性技能也分剑、钝器，沿用同一条武器路线即可。

### 枪战士 → 龙骑士 → 黑骑士

采用**枪、矛双修**，保留后续根据武器和攻击方式切换的空间。

| 技能 | 终态等级 |
| --- | ---: |
| 精准枪 | 20 |
| 精准矛 | 20 |
| 快速枪 | 20 |
| 快速矛 | 20 |
| 极限防御 | 11 |
| 神圣之火 | 30 |
| 终极枪、终极矛 | 0 |
| **合计** | **121** |

这套加法把终极的点数留给枪、矛两类武器支持，方便之后选择武器。神圣之火需要极限防御至少3级，表中11级已经足够。

本表提供二转双修支持，三转不必因此继续双修。[三转龙骑士攻略](adventurer-third-job.md#枪战士--龙骑士131-黑骑士)另列单枪、单矛与双修终态；**AI玩家推荐三转单修**，固定一类武器，减少战斗中切武器和切对应技能的操作。已按本表投入的角色也可直接选择三转单修。

## 魔法师

### 火毒法师 → 火毒巫师 → 火毒魔导师

| 技能 | 终态等级 |
| --- | ---: |
| 魔力吸收 | 20 |
| 精神力 | 20 |
| 快速移动 | 20 |
| 火焰箭 | 30 |
| 毒雾术 | 30 |
| 缓速术 | 1 |
| **合计** | **121** |

保留两种二转攻击与完整移动、魔力辅助。二转的**毒雾术（2101005）**和三转的**致命毒雾（2111003）**是不同技能，不能因名称相近而混算。

若更重视后续减速控场，可将毒雾术从30改为11、缓速术从1改为20，总数仍为121，代价是降低二转毒攻击的等级。

### 冰雷法师 → 冰雷巫师 → 冰雷魔导师

| 技能 | 终态等级 |
| --- | ---: |
| 魔力吸收 | 20 |
| 精神力 | 20 |
| 快速移动 | 20 |
| 冰冻术 | 30 |
| 雷电术 | 30 |
| 缓速术 | 1 |
| **合计** | **121** |

保留单体冰攻击与群体雷攻击。与火毒相同，精神力需要魔力吸收3级，缓速术需要本分支快速移动5级。推荐方案中的终态都满足。

### 牧师 → 祭司 → 主教

| 技能 | 终态等级 |
| --- | ---: |
| 魔力吸收 | 20 |
| 快速移动 | 20 |
| 群体治愈 | 30 |
| 神之保护 | 20 |
| 祝福 | 20 |
| 圣箭术 | 11 |
| **合计** | **121** |

以治疗、生存和组队辅助为主，圣箭术承担补充单体攻击。不要为了把圣箭术点满而误减群体治愈或辅助项。神之保护需要群体治愈5，祝福需要神之保护5；三转神圣祈祷的前置另见三转攻略。

## 弓箭手

### 猎人 → 射手 → 神射手

| 技能 | 终态等级／投入点数 |
| --- | ---: |
| 精准弓 | 20 |
| 快速箭 | 20 |
| 无形箭 | 20 |
| 爆炸箭 | 30 |
| 强弓 | 20 |
| 终极弓 | 0 |
| 一转补点 | 11点 |
| **合计** | **110＋11＝121点** |

保留群攻、近身击退与弓系支持，不投资终极弓；将余点补一转。**精准弓最终必须20级**，不能沿用“19级就够”的省点方案后忘记补满，原因见四转前置。

### 弩弓手 → 游侠 → 箭神

| 技能 | 终态等级／投入点数 |
| --- | ---: |
| 精准弩 | 20 |
| 快速弩 | 20 |
| 无形箭 | 20 |
| 穿透箭 | 30 |
| 强弩 | 20 |
| 终极弩 | 0 |
| 一转补点 | 11点 |
| **合计** | **110＋11＝121点** |

同样保留群攻、近身击退与武器支持。二转**穿透箭（3201005）**与四转同名的**穿透箭（3221001）**是不同技能，二转点满不会代替四转技能习得。精准弩终态20级也是四转前置。

**两条弓手路线的一转补点方法：**按当前一转记录，优先补集中术至20，再补精准箭至12，仍有余点就补尚未满的一转技能，合计只追加11点；已满项目跳过。这11点可以分到多个技能。传统三转会检查剩余SP，建议在转职前完成这些补点。

两条路线均须先有对应精准5级才能学快速，对应快速5级才能学无形箭。

## 飞侠

### 刺客 → 无影人 → 隐士

| 技能 | 终态等级 |
| --- | ---: |
| 精准暗器 | 20 |
| 强力投掷 | 30 |
| 恢复术 | 3 |
| 快速暗器 | 20 |
| 轻功 | 20 |
| 生命吸收 | 28 |
| **合计** | **121** |

优先保留暴击、武器支持和移动，恢复术仅投入生命吸收要求的3级。生命吸收留28，正好把点数用完；想加到30，就得从其他技能挪出2点。精准暗器最后一级还能增加暗器容量，建议加满20。

### 侠客 → 独行客 → 侠盗

| 技能 | 终态等级 |
| --- | ---: |
| 精准短刀 | 20 |
| 恢复术 | 20 |
| 快速短刀 | 20 |
| 轻功 | 20 |
| 回旋斩 | 30 |
| 神通术 | 11 |
| **合计** | **121** |

回旋斩为主要单体攻击，神通术作为低优先项。更重视偷取玩法时，可以将恢复术从20改为1、神通术从11改为30，总数仍为121。神通术需轻功5级，快速短刀需精准短刀5级。

## 海盗

### 拳手 → 斗士 → 冲锋队长

部分菜单也使用“格斗家”称呼二转拳手；本篇按职业ID **510** 识别。

| 技能 | 终态等级 |
| --- | ---: |
| 强体术 | 10 |
| 精准拳 | 20 |
| 急速拳 | 20 |
| 回马 | 20 |
| 升龙连击 | 20 |
| 贯骨击 | 20 |
| 生命分流 | 10 |
| 橡木伪装 | 1 |
| **合计** | **121** |

**强体术应尽早点满10。**它会增加后续升级时获得的HP，拖到二转结束才补满，并不会补回之前少长的HP。

急速拳需精准拳5级，而且终态20涉及四转极速领域前置。橡木伪装只保留1级，将SP留给其余战斗与补给技能；伪装期间也要留意怪物和自己的HP。

### 火枪手 → 大副 → 船长

部分菜单称“枪手”；本篇按职业ID **520** 识别，与枪战士的长枪分开。

| 技能 | 终态等级 |
| --- | ---: |
| 精准枪 | 20 |
| 速射 | 20 |
| 快枪手 | 20 |
| 投弹攻击 | 11 |
| 迷惑射击 | 20 |
| 轻羽鞋 | 10 |
| 激退射杀 | 20 |
| **合计** | **121** |

保留手枪支持、近距离群攻、控制及移动，投弹攻击作为余点项。若主要使用投弹群攻，可将投弹攻击改20、迷惑射击改11，总数仍为121。速射需精准枪5，激退射杀需轻羽鞋5。

## 为四转保留的二转要求

以下二转技能是后续四转技能的前置，推荐方案已经留足等级：

| 四转职业／技能 | 二转要求 | 本篇安排 |
| --- | --- | --- |
| 神射手：神箭手（3120005） | 精准弓（3100000）20级 | 保留20级，不省最后1点 |
| 箭神：神弩手（3220004） | 精准弩（3200000）20级 | 保留20级，不省最后1点 |
| 冲锋队长：极速领域（5121009） | 急速拳（5101006）20级 | 保留20级，不只留短时加速等级 |

其余四转职业未在技能资料中列出直接要求二转技能的前置；二转的被动、增益和武器支持仍会继续用到。召唤龙、凤凰、导航等要求的是**三转**技能，见[三转攻略的四转前置表](adventurer-third-job.md#为四转保留的三转要求)。

## 技能书与三转准备

**这些二转技能无需技能书或能手册**，满足前置后直接花SP提升即可。

四转技能的书籍获取方法暂未收录。

准备三转时，除了本职业表格，还要记得处理余点：弓手有11点补一转，剑客和准骑士最后1点可放备用武器或补一转。走弓、弩、拳路线的角色，分别把精准弓、精准弩、急速拳留到20，后面四转还需要。

若点数不够，先看看有没有把点花在表外技能上；若技能名称、上限也对不上，可能是版本差异，先留住剩余SP，查清后再补。三转任务的剩余SP要求见[三转任务攻略](adventurer-third-job-quest.md#出发前准备)。
